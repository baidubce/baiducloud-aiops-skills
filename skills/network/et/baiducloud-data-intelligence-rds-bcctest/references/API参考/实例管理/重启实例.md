# 重启实例

## 接口描述

本接口用于重启实例，支持时间窗口操作。

本接口为v1接口。

## 请求结构

Plain Text

```
PUT /v{version}/instance/{instanceId}?reboot HTTP/1.1
Host: rds.bj.baidubce.com
Content-Type: application/json
Authorization: authorization string
{
   "effectiveTime": "immediate"
}
```

## 请求头域

除公共头域外，无其它特殊头域。

## 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | Path参数 | API版本号，此处值为1 |
| instanceId | String | 是 | Path参数 | 实例ID |
| effectiveTime | String | 否 | RequestBody参数 | 操作执行方式，有两种取值：timewindow、immediate。其中timewindow表示在时间窗口内执行，immediate表示立即执行。默认为immediate。实例默认的时间窗口为05:00~06:00，具体可参考实例详情内容 |

  

## 响应头域

除公共头域外，无其它特殊头域。

## 响应参数

无

```
PUT http://rds.bj.baidubce.com/v1/instance/rds-xktdeMSs?reboot
Host: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2015-08-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de

}
```
