# 续费实例

**接口描述**

续费实例，本接口用于对已有的预付费实例进行续费。

如果预付费实例在回收站中，续费后会从回收站中恢复。

**请求结构**

Plain Text

```
POST /v1/instance/renew HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
{
    "duration" : 1,
    "instanceIds" : [ "rds-76rUXbsX" ]
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| duration | Integer | 是 | RequestBody参数 | 续费周期，单位为月 |
| instanceIds | List<String> | 是 | RequestBody参数 | 实例ID列表 |

  

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| orderId | String | 续费订单ID |

  

**请求示例**

Plain Text

```
POST http://rds.bj.baidubce.com/v1/instance/renew
Host: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2015-08-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "duration" : 1,
  "instanceIds" : [ "rds-76rUXbsX" ]
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
Content-Type: application/json
x-bce-request-id: d8752367-38e8-45e4-b4c7-e53be3137ce5
{
  "orderId" : "000000dbcd19740d000000Kfc054b80dZX"
}
```
