# 获取新购价格

### 接口描述

本接口用于查询新购实例的价格。

本接口为v1接口。

### 请求结构

Plain Text

```
POST /v{version}/instance/price HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
{
    "instance": {
        "engine": "sqlserver",
        //sqlserver单机。engineVersion取值:2012/2016
        //sqlservers双机。engineVersion取值:2008r2/2012sp3/2016sp1
        "engineVersion": "2016",
        "cpuCount": 2,
        "allocatedMemoryInGB": 8,
        "allocatedStorageInGB": 50,
        "category":"Singleton",
        "diskIoType": "cloud_enha"
    },
    "duration": 1,
    "number": 1,
    "productType": "prepay"
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号。 |
| instance | Instance | 是 | RequestBody参数 | 询价参数对象。 |
| duration | Integer | 否 | RequestBody参数 | 时长。支付方式为后支付时不需要设置，预支付时必须设置。时间单位默认为month。 |
| number | Integer | 否 | RequestBody参数 | 购买数量，默认值为1。 |
| productType | String | 是 | RequestBody参数 | 付费方式。 预付费：prepay，后付费：postpay。 |

  

**Instance**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| engine | String | 是 | RequestBody参数 | 数据库引擎类型。 |
| engineVersion | Instance | 否 | RequestBody参数 | 数据库引擎版本。 |
| cpuCount | Integer | 是 | RequestBody参数 | CPU 个数。 |
| allocatedMemoryInGB | Integer | 是 | RequestBody参数 | 内存大小，单位是 MB。 |
| allocatedStorageInGB | Integer | 是 | RequestBody参数 | 存储大小，单位是 GB。 |
| nodeAmount | Integer | 否 | RequestBody参数 | 询价代理实例时，此值必填，表示代理节点个数。 |
| diskIoType | String | 是 | RequestBody参数 | 存储磁盘包括本地SSD磁盘（取值为：normal\_io）、增强型SSD云磁盘（取值为：cloud\_enha）、 高性能云磁盘（取值为：cloud\_high）、cloud\_nor（取值为: 通用型SSD）四种。 |
| category | String | 否 | RequestBody参数 | 不传值的话默认为双机版，传 Singleton 则指定为单机版。 |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| price | BigDecimal | 常规价格。 |
| catalogPrice | BigDecimal | 目录价格。 |
| backupInGB | BigDecimal | 备份费用价格。 |
