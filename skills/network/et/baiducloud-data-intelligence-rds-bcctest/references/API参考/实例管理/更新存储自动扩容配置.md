# 更新存储自动扩容配置

**接口说明**

实例开启/关闭/修改存储自动扩容配置

**请求结构**

Plain Text

```
PUT /v{version}/instance/{instanceId}/diskAutoResize/config/{action} HTTP/1.1
HOST: rds.bj.baidubce.com
Authorization: authorization string
{
    "freeSpaceThreshold" : freeSpaceThreshold,
    "diskMaxLimit":freeSpaceThreshold
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | API 版本号 |
| instanceId | String | 是 | URL参数 | 实例ID |
| action | String | 是 | URL参数 | 取值为： - open，表示开启存储自动扩容 - stop，表示关闭存储自动扩容 - update，表示实例在开启存储自动扩容的状态下，修改可用空间阈值或者磁盘上限 |
| freeSpaceThreshold | Integer | 否 | RequestBody参数 | 可用空间阈值, 单位%。当action为open时，为必传参数，仅允许实例在启用存储自动扩容时修改 |
| diskMaxLimit | Integer | 否 | RequestBody参数 | 自动扩容磁盘的上限，单位GB。当action为open时，为必传参数，仅允许实例在启用存储自动扩容时修改。参数校验：必须为5的整倍数，必须大于实例当前磁盘quto，必须小于等于该实例变配时的磁盘上限 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**
