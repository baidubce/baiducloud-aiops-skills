# 获取指定实例的自动扩容配置信息

**接口说明**

获取指定实例的自动扩容配置信息

**请求结构**

Plain Text

```
GET /v{version}/instance/{instanceId}/autoResizeConfig HTTP/1.1
HOST: rds.bj.baidubce.com
Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API 版本号 |
| instanceId | String | 是 | URL参数 | 实例ID |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| autoResizeDisk | Integer | 实例是否启用了存储自动扩容，0表示未启用，1表示已启用 |
| freeSpaceThreshold | Integer | 可用空间阈值, 单位% |
| diskMaxLimit | Integer | 自动扩容磁盘的上限,单位GB |
| extendStepPercent | Integer | 触发自动扩容时，目标磁盘大小增长百分比，单位% |

**请求示例**

Plain Text

```
GET /v1/instance/rds-DQKfeKDd/autoResizeConfig HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
```
