# 修改描述信息

**接口说明**

修改描述信息，PG不支持修改备注。

**请求结构**

Plain Text

```
PUT /v{version}/instance/{instanceId}/databases/{dbName}/remark HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: authorization string
{
  "remark":"remark"
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | 1 | API 版本号 |
| instanceId | String | 是 | URL参数 | rds-oKf9YW9L | 实例ID |
| dbName | String | 是 | URL参数 | db\_123 | 数据库名称 |
| remark | String | 是 | RequestBody参数 | db | 描述信息 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无特殊返回参数。

**请求示例**

Plain Text

```
PUT /v1/instance/rds-oKf9YW9L/databases/db_123/remark HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "remark":"db"
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 7869616F-7A68-6977-656E-406261696475
Content-Type: application/json
```
