# 批量修改只读组名称、延迟剔除开关、延迟阈值、重新负载均衡开关、组内只读实例权重

**接口说明**

批量修改只读组名称、延迟剔除开关、延迟阈值、重新负载均衡开关、组内只读实例权重。

**请求结构**

Plain Text

```
PUT /v{version}/rds/{sourceAppId}/rogroup/{roGroupId}/updateRoGroupProperty  HTTP/1.1
HOST: rds.bj.baidubce.com
Authorization: authorization string
{
 "roGroupName": "roGroupName",
 "enableDelayOff": enableDelayOff,
 "delayThreshold": delayThreshold,
 "balanceReload": balanceReload,
 "leastAppAmount": leastAppAmount,
 "readReplicaList": [
    {
     "appId": "appId",
     "weight": weight
    }
 ]
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | API 版本号 |
| sourceAppId | String | 是 | URL参数 | 指定实例 ID |
| roGroupId | String | 是 | URL参数 | 只读组 ID |
| sourceAppId | String | 否 | RequestBody参数 | 指定实例 ID |
| roGroupId | String | 否 | RequestBody参数 | 只读组 ID |
| roGroupName | String | 否 | RequestBody参数 | 只读组的名称 |
| enableDelayOff | Boolean | 否 | RequestBody参数 | 只读组的延迟自动剔除开关 |
| delayThreshold | Integer | 否 | RequestBody参数 | 延迟阈值，取值为大于等于0的整数，范围1-2147483646 |
| balanceReload | Boolean | 否 | RequestBody参数 | 只读组的重新负载均衡开关 |
| leastAppAmount | Integer | 否 | RequestBody参数 | 组内最少保留实例数目，取值为0~5之间的整数。默认为1 |
| readReplicaList | List<readReplica> | 否 | RequestBody参数 | 要修改权重的只读实例列表 建议范围：1-100 |

**readReplica**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| appId | String | 是 | readReplica对象内 | 只读实例 ID |
| weight | Integer | 是 | readReplica对象内 | 修改后的权重 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无特殊返回参数。
