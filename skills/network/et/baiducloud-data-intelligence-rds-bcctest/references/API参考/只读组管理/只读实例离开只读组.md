# 只读实例离开只读组

**接口说明**

只读实例离开只读组。

**请求结构**

Plain Text

```
PUT /v{version}/rds/{sourceAppId}/rogroup/{roGroupId}/leave  HTTP/1.1
HOST: rds.bj.baidubce.com
Authorization: authorization string
{
 "readReplicaList": ["readReplicaList"]
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | API 版本号 |
| sourceAppId | String | 是 | URL参数 | 指定实例ID |
| roGroupId | String | 是 | URL参数 | 只读组ID |
| readReplicaList | List<String> | 是 | RequestBody参数 | 要离开的只读实例ID列表 ,多个逗号分隔 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无特殊返回参数。

**请求示例**

Plain Text

```
PUT /v1/rds/rdsmdhy7nez83hh/rogroup/rdsmrg-87srhtgn/leave HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de 
{
 "readReplicaList":["rds-wI2F7KOC"]
}
```

Plain Text
