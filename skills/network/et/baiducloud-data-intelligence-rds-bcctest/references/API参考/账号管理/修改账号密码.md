# 修改账号密码

**接口说明**

在某个主实例下修改账号的密码。

**请求结构**

Plain Text

```
PUT /v{version}/instance/{instanceId}/account/{accountName}/password HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
X-Bce-Accesskey：AccessKey
Authorization: authorization string
{
  "password":password
}
```

**请求头域**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| X-Bce-Accesskey | String | 是 | requestHeader | 请求iam 必带的accessKey参数 |

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | API 版本号 |
| instanceId | String | 是 | URL参数 | 指定实例 ID |
| accountName | String | 是 | URL参数 | 账号名称 |
| password | String | 是 | RequestBody参数 | 账号的密码，由字母、数字或下划线组成，长度6～32位 密码需要加密传输，禁止明文传输，详情请参考[密码加密传输规范定义](https://cloud.baidu.com/doc/RDS/s/Ejwvz0uoq#%E5%AF%86%E7%A0%81%E5%8A%A0%E5%AF%86%E4%BC%A0%E8%BE%93%E8%A7%84%E8%8C%83%E5%AE%9A%E4%B9%89) |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无特殊返回参数。

**请求示例**

Plain Text

```
PUT /v1/instance/rds-oKf9YW9L/account/test_nameone/password HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
X-Bce-Accesskey：53fc7a7e803344dhh2e1e4763ebe5xxxx
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "password":"51a3f85faef04b7317097c1c3746b531"
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 7869616F-7A68-6977-656E-406261696475
Content-Type: application/json
```
