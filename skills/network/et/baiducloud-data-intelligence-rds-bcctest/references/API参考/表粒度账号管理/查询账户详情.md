# 查询账户详情

## 查询账户详情

### 接口描述

本接口用于查询账户详情，目前仅支持 MySQL

本接口为v2接口

### 请求结构

Plain Text

```
POST /v{version}/instance/account/tableLevel/detail HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
Content-Type: application/json
{
    "instanceId": "rds-LxEukFGp",
    "user": "test_lll",
    "host": "%"
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号，此处值为2。 |
| instanceId | String | 是 | RequestBody参数 | 实例 ID |
| user | String | 是 | RequestBody参数 | 账户名 |
| host | String | 是 | RequestBody参数 | 主机地址 |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数
