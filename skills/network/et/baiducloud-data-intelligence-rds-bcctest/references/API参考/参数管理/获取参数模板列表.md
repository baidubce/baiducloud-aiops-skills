# 获取参数模板列表

### 接口描述

* 本接口用于获取参数模板列表。
* 本接口为v1接口。

### 请求结构

Plain Text

```
GET /v{version}/instance/paraTemplate?pageNo=1&pageSize=10&type=system HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
Content-Type: application/json;charset=UTF-8
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | API版本号。 |
| pageNo | Integer | 是 | Query参数 | 页号。 |
| pageSize | Integer | 是 | Query参数 | 页的大小。 |
| type | String | 否 | Query参数 | 模板类型，支持user/system，不传默认为user。user：返回自定义参数列表；system：返回系统参数列表。 |
| dbType | String | 否 | Query参数 | 数据库类型。 |
| dbVersion | String | 否 | Query参数 | 数据库版本。 |

  

### 响应头域

除公共头域外，无其它特殊头域。

  

### 请求示例

Plain Text

```
GET http://rds.bj.baidubce.com/v1/instance/paraTemplate?pageNo=1&pageSize=10&type=user
Host: rds.bj.baidubce.com
Content-Type: application/json;charset=UTF-8
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2015-08-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
```
