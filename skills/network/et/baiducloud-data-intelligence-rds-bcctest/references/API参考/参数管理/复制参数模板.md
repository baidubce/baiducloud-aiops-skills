# 复制参数模板

### 接口描述

* 本接口用于复制参数模板。
* 本接口为v1接口。

### 请求结构

Plain Text

```
POST /v{version}/instance/paraTemplate/duplicate/template HTTP/1.1
Host: rds.bj.baidubce.com
Content-Type: application/json;charset=UTF-8
Authorization: authorization string
{
    "name": "lll_name1",
    "desc": "lll_test1",
    "templateId" : "309"
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | API版本号。 |
| name | String | 是 | RequestBody参数 | 复制后模板的名称。 |
| desc | String | 是 | RequestBody参数 | 复制后模板的备注。 |
| templateId | String | 是 | RequestBody参数 | 复制的模板 ID。 |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

无

### 请求示例

Plain Text

```
POST http://rds.bj.baidubce.com/v1/instance/paraTemplate/duplicate/template
Host: rds.bj.baidubce.com
Content-Type: application/json;charset=UTF-8
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2015-08-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    "name": "lll_name1",
    "desc": "lll_test1",
    "templateId" : "309"
}
```
