# 修改配置参数

**说明**

修改云数据库 RDS for MySQL 的参数配置。

**请求结构**

Plain Text

```
PUT /v{version}/instance/{instanceId}/parameter HTTP/1.1
HOST: rds.bj.baidubce.com
x-bce-if-match: {ETag}
Authorization: authorization string
{
    "parameters" : parameters，
    "effectiveTime":effectiveTime
}
```

**请求头域**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| x-bce-if-match | string | 通过查询接口获取到的ETag值 |

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | 1 | API版本号 |
| instanceId | String | 是 | URL参数 | rds-87Tx7SwY | 实例ID |
| effectiveTime | String | 是 | RequestBody参数 | immediate | 实际生效方式：立即执行（immediate）、维护时间执行（timewindow） |
| parameters | List<parameter> | 是 | RequestBody参数 | [{"name":"wait\_timeout","value":"86300","etag":"v1","applyMethod":"immediate"}] | 需要修改的参数列表 |

**Parameter结构**

| 参数名称 | 类型 | 示例值 | 描述 |
| --- | --- | --- | --- |
| name | String | wait\_timeout | 参数名 |
| value | String | 86300 | 参数取值 |
| applyMethod | String | immediate | 建议参数生效方式：立即执行（immediate）、维护时间执行（timewindow）。 此参数省略或为空并from为api 系统默认applyMethod参数值为immediate参数 |
| etag | String | v1 | 版本号 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无特殊返回参数。

**请求示例**

Plain Text

```
PUT /v1/instance/rds-87Tx7SwY/parameter HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type:application/json
x-bce-if-match: v1
Authorization: bce-auth-v1/rdsak/2016-07-03T06:13:13Z/1800/x-bce-date/{signature}
{
"parameters":[
    {"name":"wait_timeout",
    "value":"86300",
    "etag":"v1",
    "applyMethod":"immediate"
    }],
 "effectiveTime":"immediate"
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 7869616F-7A68-6977-656E-406261696475
Content-Type: application/json
```
