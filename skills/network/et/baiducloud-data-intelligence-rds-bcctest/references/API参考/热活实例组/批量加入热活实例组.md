# 批量加入热活实例组

**接口描述**

本接口用于批量加入实例至热活实例组。

**注意事项**

加入热活实例组，需满足以下前置条件：

* 热活实例组仅支持MYSQL 5.6/5.7版本
* 主实例的同步模式必须为异步同步
* 主实例必须启用GTID
* 主实例ID所在地域必须与当前请求的地域保持一致
* 批量加入的leader节点也不能在当前实例组内

**请求结构**

Plain Text

```
POST /v1/instance/group/batchjoin HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
{
  "followerIds" : ["rds-bbb","rds-aaa"],
  "name":"name",
  "leaderId":"rds-ccc"
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| leaderId | String | 是 | RequestBody参数 | rds-wDVcXRq5 | 主实例ID |
| followerIds | List<String> | 是 | RequestBody参数 | ["rds-45M91v08"] | 从实例数组 |
| name | String | 是 | RequestBody参数 | testone | 热活实例组名称 |

  

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

无特殊请求参数

**请求示例**

Plain Text

```
POST http://rds.bj.baidubce.com/v1/instance/group/batchjoin
Host: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2023-10-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "followerIds":["rds-45M91v08"],
  "name":"testone",
  "leaderId":"rds-wDVcXRq5"
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
Content-Type: application/json
x-bce-request-id: d8752367-38e8-45e4-b4c7-e53be3137ce5
```
