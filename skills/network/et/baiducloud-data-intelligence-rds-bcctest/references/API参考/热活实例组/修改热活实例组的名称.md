# 修改热活实例组的名称

**接口描述**

本接口用于修改热活实例组的名称。

本接口为v1接口。

**请求结构**

Plain Text

```
POST /v{version}/instance/group/{groupId}/name HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
{
  "name":"name"
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | 1 | URL参数 |
| groupId | String | 是 | rdcae1buf7f | URL参数 |
| name | String | 是 | yhgroup\_7788 | RequestBody参数 |

  

**响应头域**

除公共头域外，无其它特殊头域。

**响应参数**

无

**请求示例**

Plain Text

```
POST http://rds.bj.baidubce.com/v1/instance/group/rdcae1buf7f/name HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "name":"yhgroup_7788"
}
```

**响应示例**

Plain Text

```
HTTP/1.1 200 OK
Content-Type: application/json
x-bce-request-id: d8752367-38e8-45e4-b4c7-e53be3137ce5
```
