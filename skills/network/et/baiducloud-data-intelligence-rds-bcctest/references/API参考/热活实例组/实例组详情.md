# 实例组详情

## 接口描述

本接口用于查询实例组详情。

本接口为v1接口。

## 请求结构

Plain Text

```
GET /v{version}/instance/group/{groupId} HTTP/1.1
Host: rds.bj.baidubce.com
Content-Type: application/json
Authorization: authorization string
```

## 请求头域

除公共头域外，无其它特殊头域。

## 请求参数

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | Path参数 | API 版本号，此处值为1 |
| groupId | String | 是 | Path参数 | 实例组Id |

  

## 响应头域

除公共头域外，无其它特殊头域。

## 响应参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| group | Group | 实例组详情 |

  

## Group详情

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| groupId | String | 实例组Id |
| name | String | 实例名称 |
| count | Integer | 主实例数量 |
| leader | Instance | 主角色 |
| followers | List Instance | 从角色列表 |

  

## Instance详情

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| instanceIdShort | String | 实例Id |
| region | String | 地域 |
| azone | String | 可用区 |
| status | String | 实例状态 |
| lockMode | String | 锁定模式 |
| name | String | 实例名称 |
