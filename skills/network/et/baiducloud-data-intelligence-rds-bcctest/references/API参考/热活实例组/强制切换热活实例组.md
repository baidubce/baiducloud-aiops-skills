# 强制切换热活实例组

**接口说明**

强制切换热活实例组，新主角色ID所在地域必须与当前请求的地域保持一致。

**请求结构**

Plain Text

```
PUT /v{version}/instance/group/{groupId}/forceChange
Host: rds.bj.baidubce.com
Content-Type: application/json
Authorization: authorization string
{
  "force" : force,
  "leaderId" : "leaderId",
  "maxBehind" : maxBehind
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 参数类型 | 是否必须 | 示例值 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- | --- |
| version | Integer | 是 | 1 | URL参数 | API 版本号 |
| groupId | String | 是 | rds\_hotgroup | URL参数 | 实例组ID |
| leaderId | String | 是 | rds-y9dJu77d | requestBody参数 | 实例组中要切换为主角色的实例ID |
| force | Integer | 否 | 1 | requestBody参数 | 0 - 非故障（非故障状态时使用）1 - 故障 |
| maxBehind | Integer | 否 | 10 | requestBody参数 | 最大允许备库Behind\_Master值（0 表示要求备库和故障主库数据完全一致，建议业务从0开始逐步增加，直至最大容忍值，force=0时，该参数不生效 ） |

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

| 参数名称 | 参数类型 | 描述 | 示例值 |
| --- | --- | --- | --- |
| behindMaster | Integer | 切换时备库延迟 | 0 |

**请求示例**

Plain Text

```
PUT http://rds.bj.baidubce.com/v1/instance/group/rds_hotgroup/forceChangeforceChange HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "force" : 1,
  "leaderId" : "rds-y9dJu77d",
  "maxBehind" : 10
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
Content-Type:application/json
x-bce-request-id:d8752367-38e8-45e4-b4c7-e53be3137ce5
{
  "behindMaster" : 0
}
```
