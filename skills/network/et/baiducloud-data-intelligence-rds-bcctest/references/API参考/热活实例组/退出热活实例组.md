# 退出热活实例组

**接口描述**

本接口用于退出热活实例组，传入实例instanceId所在地域必须与当前请求的地域保持一致。

本接口为v1接口。

**请求结构**

Plain Text

```
DELETE /v{version}/instance/group/{groupId}/instance/{instanceId} HTTP/1.1
Host: rds.bj.baidubce.com
Content-Type: application/json
Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | 1 | URL参数 |
| groupId | String | 是 | rdcae1buf7f | URL参数 |
| instanceId | String | 是 | rds-87Tx7SwY | URL参数 |

  

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

无

**请求示例**

Plain Text

```
DELETE http://rds.bj.baidubce.com/v1/instance/group/rds-87Tx7SwY/instance/rds-87Tx7SwY HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
Content-Type: application/json
x-bce-request-id: d8752367-38e8-45e4-b4c7-e53be3137ce5
```
