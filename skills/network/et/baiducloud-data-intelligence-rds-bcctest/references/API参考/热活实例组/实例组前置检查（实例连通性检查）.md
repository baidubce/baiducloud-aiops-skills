# 实例组前置检查（实例连通性检查）

**接口描述**

本接口用于实例组前置检查（实例连通性检查），当前请求的地域必须与sourceId所在地域保持一致。

本接口为v1接口。

**请求结构**

Plain Text

```
POST /v{version}/instance/group/checkPing HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
{
  "sourceId":"sourceId",
  "targetId":"targetId"
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 示例值 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- | --- |
| version | Integer | 是 | 1 | URL参数 | API 版本号，此处值为1 |
| sourceId | String | 是 | rds-0ftLecci | RequestBody参数 | 源实例ID(要加入实例组的实例ID) |
| targetId | String | 是 | rds-WwTwwz2G | RequestBody参数 | 目标实例ID(实例组的主角色实例ID) |

  

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| result | Boolean | 成功：true；失败：false |

  

**请求示例**

Plain Text

```
POST http://rds.bj.baidubce.com/v1/instance/group/checkPing HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "sourceId":"rds-0ftLecci",
  "targetId":"rds-WwTwwz2G"
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
Content-Type: application/json
x-bce-request-id: d8752367-38e8-45e4-b4c7-e53be3137ce5
{
  "result": true
}
```
