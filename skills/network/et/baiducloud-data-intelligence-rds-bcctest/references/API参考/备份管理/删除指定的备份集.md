# 删除指定的备份集

**接口说明**

删除指定的备份集

**注意事项**

删除备份集只能删除手动全量备份到备份集

**请求接口**

Plain Text

```
DELETE /v{version}/instance/{instanceId}/backup/{snapshotId} HTTP 1.1
HOST: rds.bj.baidubce.com
Authorization:authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 参数类型 | 是否必须 | 描述 | 示例值 | 参数位置 |
| --- | --- | --- | --- | --- | --- |
| version | Integer | 是 | API版本号 | 1 | URL参数 |
| instanceId | String | 是 | 实例 ID | rds-JGroEX60 | URL参数 |
| snapshotId | String | 是 | 手动全量备份 ID | 1688569205551435771 | URL参数 |

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

无

**请求示例**

Plain Text

```
DELETE /v1/instance/rds-JGroEX60/backup/1688569205551435771 HTTP 1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
Content-Type: application/json;charset=UTF-8
x-bce-request-id: d8752367-38e8-45e4-b4c7-e53be3137ce5
```
