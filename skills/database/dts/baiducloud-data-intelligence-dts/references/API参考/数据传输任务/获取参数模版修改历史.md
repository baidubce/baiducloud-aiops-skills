# 获取参数模版修改历史

## 获取参数模版修改历史

### 接口描述

获取任务修改过的参数列表历史记录

### 请求结构

Plain Text

```
GET /v{version}/task/parameters/history?dtsId=dtsxxxxxxxx
Host: dts.baidubce.com
Authorization: authorization string
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号。 |
| dtsId | String | 是 | Query参数 | 根据任务id查询任务的参数模版信息，可以是迁移任务或独立数据校验任务 |
| dataType | String | 否 | Query参数 | 可选值schema，base， increment；不传此参数默认返回当前任务所有迁移类型的参数修改历史 |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| success | Boolean | 是否成功。 |
| result | List<Params> | 参数模版结果。 |

### Params字段数据结构说明

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| name | String | 参数名 |
| newValue | String | 参数当前值 |
| oldValue | String | 参数旧值 |
| dataType | String | schema(结构迁移)，base(全量迁移)，increment(增量同步) |
| modifyTime | String | 变更时间（UTC时间） |
| status | String | 参数状态： modifying 变更中，finished 已完成，failed 变更失败 |

  

### 请求示例

Plain Text

