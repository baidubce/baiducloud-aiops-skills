# 更新任务名称

## 接口说明

更新任务名称

## 请求结构

```
PUT /v{version}/task/{dtsId}?name
Host: dts.baidubce.com    
Authorization: authorization string 
{
    "taskName": "newName"
}
```

## 请求url参数

| 参数名称 | 参数类型 | 是否必须 | 描述 | 示例值 | 参数位置 |
| --- | --- | --- | --- | --- | --- |
| **version** | String | 是 | API版本号 | "1" | URL参数 |
| **dtsId** | String | 是 | dts任务Id | dtsmxxxxx | URL参数 |

## 请求体参数

| 参数名称 | 参数类型 | 是否必须 | 描述 | 示例值 | 参数位置 |
| --- | --- | --- | --- | --- | --- |
| taskName | String | 是 | 更新后的名字 | newName | Request Body 参数 |

## 响应头参数

除公共头域，无其它特殊头域。

## 请求示例

```
PUT /v1/task/dtsmxxxxxxxxx?name
Host: dts.baidubce.com    
Content-Type: application/json     
Authorization: authorization string
{
    "taskName": "newName"
}
```

## 响应示例

```
HTTP/1.1 200 OK
```
