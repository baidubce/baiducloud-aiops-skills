# 变更链路规格

## 接口说明

变更链路规格

## 变配接口操作范围

仅限任务状态为：'running', 'stopped', 'runFailed'

## 请求结构

```
PUT /v{version}/task/{dtsId}?standard
Host: dts.baidubce.com    
Authorization: authorization string
{
  "standard" : "Large"
}
```

## 请求参数

| 参数名称 | 参数类型 | 是否必须 | 描述 | 示例值 | 参数位置 |
| --- | --- | --- | --- | --- | --- |
| **version** | **String** | 是 | API版本号 | 1 | URL参数 |
| **dtsId** | **String** | 是 | 任务ID | dtsmxxxyyy | URL参数 |
| **standard** | **String** | 是 | 实例规格（small；medium；large；xlarge），性能详情参见[链路规格说明](https://cloud.baidu.com/doc/DTS/s/Kkzccswc0) | large | Request Body 参数 |
| **sliceNum** | **Integer** | 否 | 修改并发消费者数量（源端为kafka时，此参数生效） | 3 | Request Body 参数 |

## 响应头参数

除公共头域，无其它特殊头域。

## 响应体参数

| 参数名称 | 参数类型 | 是否必须 | 描述 | 示例值 |
| --- | --- | --- | --- | --- |
| **orderId** | **String** | 是 | 订单ID | 98765432111111 |

## 请求示例

```
PUT /v1/task/{dtsId}?standard
Host: dts.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/5a6f0606bf5e48f29dd132aa76aa5182/2017-06-12T13:13:05Z/1800/content-type;host;x-bce-date/8baeafe6bfc35b0cf6205e87e4ce6c0dbb442375951ace4d16e6c7a4dab95943
{
  "standard" : "Large"
}
```

## 响应示例

```
HTTP/1.1 200 OK

{
  "orderId":"98765432111111"
}
```
