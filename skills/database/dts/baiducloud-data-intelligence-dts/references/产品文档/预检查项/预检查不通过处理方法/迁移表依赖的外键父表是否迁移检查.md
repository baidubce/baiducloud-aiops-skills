# 迁移表依赖的外键父表是否迁移检查

## 问题描述

为保障数据传输任务的顺利运行，DTS任务会在预检查阶段检查迁移表依赖的外键父表是否迁移。

## 问题原因

迁移的表的外键依赖的表没有迁移时预检查会失败。

## 问题的处理方法

登录[数据传输DTS控制台](https://console.bce.baidu.com/dts/?_=1651824824400#/dts/migration/list)，
点击**配置任务**按钮，选择库表信息时，将依赖的表一起迁移。
