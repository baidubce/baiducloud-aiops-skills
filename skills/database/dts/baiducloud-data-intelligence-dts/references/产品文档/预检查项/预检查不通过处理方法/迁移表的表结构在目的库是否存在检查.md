# 迁移表的表结构在目的库是否存在检查

## 问题描述

为保障数据传输任务的顺利运行，DTS任务会在预检查阶段检查迁移表的表结构在目的库是否存在。

## 问题原因

目标库中不存在待迁移的表结构时预检查会失败。

## 问题的处理方法

### 方法1：重新配置DTS任务

登录[数据传输DTS控制台](https://console.bce.baidu.com/dts/?_=1651824824400#/dts/migration/list)，
点击**配置任务**按钮，迁移对象增加结构迁移。

![image.png](https://bce.bdstatic.com/doc/bce-doc/DTS/image_da36e8e.png)

### 方法2：目标库创建待迁移表

登录目标库，在目标库中创建要迁移的表。
