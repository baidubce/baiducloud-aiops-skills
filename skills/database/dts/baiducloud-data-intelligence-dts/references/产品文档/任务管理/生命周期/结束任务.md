# 结束任务

对于需要停止或不再需要的任务，您可以结束任务，以避免源端的数据覆盖写入至目标端中。

## 前提条件

任务不处于 **任务结束** 状态。

## 注意事项

DTS 任务结束后，实例将处于 **任务结束** 状态且无法重新启动，只能复制任务，请谨慎执行结束实例的操作。

## 操作步骤

### 结束指定任务

1. 登录 [DTS 控制台](https://console.bce.baidu.com/dts/#/dts/migration/list)。
2. 选择目标迁移任务，点击 **更多操作—>结束**。
3. 在弹出的窗口中，确认无误后，点击 **确认**。

### 批量结束任务

1. 登录 [DTS 控制台](https://console.bce.baidu.com/dts/#/dts/migration/list)。
2. 勾选需要结束的迁移任务，在页面上方，点击 **结束**。
3. 在弹出的窗口中，确认无误后，点击 **确认**。
