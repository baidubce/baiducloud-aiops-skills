# 数据库智能驾驶舱 DBSC

| 指标英文名称（metric name） | 指标中文名称 | 单位 | 维度 | 备注 |
| --- | --- | --- | --- | --- |
| HighAuditLogCount | 高风险审计日志数量 | 个 | appId |  |
| MiddleAuditLogCount | 中风险审计日志数量 | 个 | appId |  |
| LowAuditLogCount | 低风险审计日志数量 | 个 | appId |  |
