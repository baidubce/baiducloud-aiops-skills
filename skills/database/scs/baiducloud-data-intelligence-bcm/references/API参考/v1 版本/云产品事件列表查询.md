# 云产品事件列表查询

## 接口描述

该接口可用于查询某个云产品下事件列表

## 请求结构

* method：POST
* 请求URL：/event-api/v1/event/metaList

## 请求参数

| 名称 | 类型 | 描述 | 是否必须 | 参数位置 |
| --- | --- | --- | --- | --- |
| scope | String | 云产品标识，取值请参考[云产品标识列表](/doc/BCM/s/Ulucfgod5) | 是 | Body参数 |
| eventTypes | String[] | 事件类型列表，个数最大为100。为空时返回所有的事件类型 | 否 | Body参数 |
| eventLevel | String | 事件级别，可选值：NOTICE、CRITICAL、MAJOR、WARNING | 否 | Body参数 |
| pageNo | Integer | 分页参数。默认值：1 | 否 | Body参数 |
| pageSize | Integer | 分页最大数量。默认值10。最大值：10000。 | 否 | Body参数 |

## 请求示例

```
{
	"scope": "BCE_BCC",
	"pageSize": 20,
	"pageNo": 1,
	"eventLevel": "WARNING",
	"eventTypes": [
		"AttachingTagsFail"
	]
}
```

## 响应示例

```
{
	"code": "200",
	"message": null,
	"requestId": "cdd77a52727b46e1bbdf24dda5ac0dc5",
	"success": true,
	"totalCount": 1,
	"events": [
		{
			"scope": "BCE_BCC",
			"type": "AttachingTagsFail",
			"description": "创建BCC标签绑定失败",
			"level": "WARNING"
		}
	]
}
```
