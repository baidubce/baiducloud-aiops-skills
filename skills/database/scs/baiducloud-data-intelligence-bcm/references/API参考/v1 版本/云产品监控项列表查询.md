# 云产品监控项列表查询

## 接口描述

该接口可用于查询某个云产品下监控项列表

## 请求结构

* method：POST
* 请求URL：/csm/api/v1/meta/metric/list

## 请求参数

| 名称 | 类型 | 描述 | 是否必须 | 参数位置 |
| --- | --- | --- | --- | --- |
| scope | String | 云产品标识，取值请参考[云产品标识列表](/doc/BCM/s/Ulucfgod5) | 是 | Body参数 |
| resourceType | String | 监控对象类型，取值请参考[云产品监控对象类型列表](/doc/BCM/s/Ulucfgod5)，为空时返回所有监控对象类型的监控项 | 否 | Body参数 |
| metricNames | String[] | 监控项名称，为空时返回所有监控项 | 否 | Body参数 |
| pageNo | Integer | 分页参数。默认值：1 | 否 | Body参数 |
| pageSize | Integer | 分页最大数量。默认值10。最大值：10000。 | 否 | Body参数 |

## 请求示例

```
{
	"scope": "BCE_MQ_KAFKA",
	"resourceType": "Node",
	"pageNo": 1,
	"pageSize": 1000,
	 "metricNames":[
		"NetReceiveBandwidthUsedPercent" 
	 ]
}
```
