# 账号列表

## 账号列表

### 接口描述

本接口用于查询账号列表。

**注意事项**

### 请求结构

Plain Text

```
GET /v{version}/instance/{instanceId}/aclUserActions HTTP/1.1
Host: redis.bj.baidubce.com
Authorization: authorization string
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | PATH参数 | API版本号。此处值为2。 |
| instanceId | String | 是 | PATH参数 | 集群ID。 |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| success | Boolean | 请求是否成功。 |
| result | List<ListItem> | 账号列表。 |

  

#### ListItem

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| userName | String | 账号名称。 |
| updateStatus | Integer | 账号状态。0：正常可用；1：创建中；2：修改中；4：删除中； |
| extra | String | 备注信息。 |
| userType | Integer | 账号权限。1：读写；2：只读； |

### 请求示例

Plain Text

```
GET http://redis.bj.baidubce.com/v2/instance/scs-bj-wqocnchhrqft/aclUserActions
Host: redis.bj.baidubce.com

```
