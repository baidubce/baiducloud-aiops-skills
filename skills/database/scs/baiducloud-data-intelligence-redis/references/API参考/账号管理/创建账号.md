# 创建账号

## 创建账号

### 接口描述

本接口用于创建集群账号。

### 请求结构

Plain Text

```
POST /v{version}/instance/{instanceId}/aclUserActions HTTP/1.1
Host: redis.bj.baidubce.com
Authorization: authorization string
{
    "userName": "name",
    "clientAuth": "fb8862d028d5c17aeb419ef655f6b004",
    "extra": "",
    "userType": 2
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | PATH参数 | API版本号。此处值为2。 |
| instanceId | String | 是 | PATH参数 | 集群ID。 |
| userName | String | 是 | RequestBody参数 | 账号名称。由小写字母、数字、下划线组成、字母开头,字母或数字结尾,最长16个字符。 |
| clientAuth | String | 是 | RequestBody参数 | 账号密码。详情请参考[密码加密传输规范定义](/doc/SCS/s/fjwvxtrd9#%E5%AF%86%E7%A0%81%E5%8A%A0%E5%AF%86%E4%BC%A0%E8%BE%93%E8%A7%84%E8%8C%83%E5%AE%9A%E4%B9%89) |
| extra | String | 否 | RequestBody参数 | 备注 |
| userType | Integer | 是 | RequestBody参数 | 账号权限。1：读写；2：只读； |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

无。

### 请求示例

Plain Text

```
POST http://redis.bj.baidubce.com/v2/instance/scs-bj-wqocnchhrqft/aclUserActions
Host: redis.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2015-08-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    "userName": "name",
    "clientAuth": "fb8862d028d5c17aeb419ef655f6b004",
    "extra": "",
    "userType": 2
}
```
