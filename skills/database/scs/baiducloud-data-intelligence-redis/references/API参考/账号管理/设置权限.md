# 设置权限

## 设置权限

### 接口描述

本接口用于设置指定账号的权限。

### 请求结构

Plain Text

```
POST /v{version}/instance/{instanceId}/aclUserActions/authority HTTP/1.1
Host: redis.bj.baidubce.com
Authorization: authorization string
{
    "userName": "cll_test",
    "userType": 2
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | PATH参数 | API版本号。 |
| instanceId | String | 是 | PATH参数 | 集群ID。 |
| userName | String | 是 | RequestBody参数 | 要设置的账号名称。 |
| userType | Integer | 是 | RequestBody参数 | 该账号设置的权限。1：读写；2：只读； |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

无。

### 请求示例

Plain Text

```
POST http://redis.bj.baidubce.com/v2/instance/scs-bj-wqocnchhrqft/aclUserActions/authority
Host: redis.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2015-08-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    "userName": "cll000",
    "userType": 2
}
```
