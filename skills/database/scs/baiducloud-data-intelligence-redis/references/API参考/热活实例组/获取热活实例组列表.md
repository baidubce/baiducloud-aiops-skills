# 获取热活实例组列表

### 请求说明

获取热活实例组列表。

### 请求结构

Plain Text

```
POST /v2/group/list HTTP/1.1
HOST: redis.{region}.baidubce.com
Authorization: authorization string
{
    pageNo: 1,
    pageSize: 10
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 描述 | 是否必填 |
| --- | --- | --- | --- |
| pageSize | int | 每页数量 | 是 |
| pageNo | int | 页码 | 是 |

  

### 返回头域

除公共头域外，无其它特殊头域。

### 返回参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| result | List<Result> | 列表结果 |
| totalCount | int | 数据总量 |
| pageNo | int | 当前页码 |
| pageSize | int | 每页显示的数量 |

  

#### Result参数信息

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| leaderName | String | 主角色的名称 |
| leaderShowId | String | 主角色的ID |
| leaderRegion | String | 主角色的地域 |
| groupId | String | 实例组ID |
| groupName | String | 实例组名称 |
| groupStatus | String | 实例组状态 |
| clusterNum | Integer | 实例组的集群数量 |
| groupCreateTime | String | 实例组创建时间 |
| forbidWrite | Integer | 禁写标志（0 未禁写， 1 禁写） |
| groupType | String | 实例组类型。标准版：standalone；集群版：bdrp |

```
    pageNo: 1,
    pageSize: 10
}
```
