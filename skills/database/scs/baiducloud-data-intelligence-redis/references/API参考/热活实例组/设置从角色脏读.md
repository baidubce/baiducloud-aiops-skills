# 设置从角色脏读

### 请求说明

设置从角色脏读：

* Redis集群版支持；Redis标准版不支持。

### 请求结构

Plain Text

```
PUT /v2/group/{groupId}/stale_readable HTTP/1.1
Host: redis.{region}.baidubce.com
Authorization: authorization string
{
    followerId: "followerId",
    staleReadable: staleReadable
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| groupId | String | 是 | URL参数 | 热活实例组ID |
| followerId | String | 是 | RequestBody参数 | 从角色集群ID |
| staleReadable | Boolean | 是 | RequestBody参数 | 是否开启从角色脏读（true：开启，false：关闭） |

  

### 返回头域

除公共头域外，无其它特殊头域。

### 返回参数

无特殊返回参数。

### 请求示例

Plain Text

```
PUT /v2/group/scs-group-qpplfjtozixy/stale_readable HTTP/1.1
HOST: redis.bj.baidubce.com
Content-Type: application/json 
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    followerId: "scs-bj-ttegbirwfagl",
    staleReadable: true
}
```

### 返回示例

Plain Text

```
HTTP/1.1 200 OK
Content-Type: application/json;charset=UTF-8
x-bce-request-id: d8752367-38e8-45e4-b4c7-e53be3137ce5
```
