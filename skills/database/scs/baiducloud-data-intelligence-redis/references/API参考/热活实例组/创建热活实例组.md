# 创建热活实例组

### 请求说明

创建热活实例组。

### 请求结构

Plain Text

```
POST /v2/group/create HTTP/1.1
Host: redis.{region}.baidubce.com
Authorization: authorization string
 {
  "leader" : {
    "groupName" : "groupName",
    "leaderRegion" : "leaderRegion",
    "leaderId" : "leaderId"
  }
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| leader | [Leader](#leader) | 是 | RequestBody参数 | 主角色信息 |

  

#### Leader

| 参数名称 | 类型 | 是否必选 | 描述 |
| --- | --- | --- | --- |
| groupName | String | 是 | 热活实例组名称。规则：支持大小写字母、数字以及-\_.等特殊字符，长度6~32 |
| leaderId | String | 是 | 主角色实例ID |
| leaderRegion | String | 是 | 主角色地域 |

### 返回头域

除公共头域外，无其它特殊头域。

### 返回参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| groupId | String | 热活实例组ID |

```

Content-Type: application/json

    "leaderId" : "scs-bdbl-dzkqigawuhzy"
  }
```
