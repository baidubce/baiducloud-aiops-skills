# 热活实例组详情

### 请求说明

热活实例组详情。

### 请求结构

Plain Text

```
GET /v2/group/{groupId} HTTP/1.1
Host: redis.{region}.baidubce.com
Authorization: authorization string
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| groupId | String | 是 | URL参数 | 待查询的热活实例组ID |

  

### 请求头域

除公共头域外，无其它特殊头域。

### 返回参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| leader | [Leader](#leader) | 主角色信息 |
| followers | List<[Followers](#followers)> | 从角色信息 |
| groupId | String | 实例组ID |
| groupName | String | 实例组名称 |
| groupStatus | String | 实例组状态 |
| clusterNum | Integer | 实例组的集群数量 |
| groupCreateTime | String | 实例组创建时间 |
| forbidWrite | Integer | 禁写标志（0 未禁写， 1 禁写） |
| groupType | String | 实例组类型。标准版：standalone；集群版：bdrp |

  

#### Leader

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| clusterName | String | 主角色实例名称 |
| clusterShowId | String | 主角色实例ID |
| region | String | 主角色地域 |
| status | String | 主角色实例状态 |
| totalCapacityInGB | Float | 总容量 |
| usedCapacityInGB | Integer | 已用容量 |
| shardNum | Integer | 分片数 |
| flavor | Integer | 单分片容量 |
| qpsWrite | Long | 写流量阈值 |
| qpsRead | Long | 读流量阈值 |
| staleReadable | Boolean | 从角色脏读开关状态（true:打开， false:关闭） |
| forbidWrite | Integer | 禁写标志（0 未禁写， 1 禁写） |
| availabilityZone | String | 可用区 |
| expiredTime | Date | 过期时间 |

#### Followers

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| clusterName | String | 从角色实例名称 |
| clusterShowId | String | 从角色实例ID |
| region | String | 从角色地域 |
| status | String | 从角色实例状态 |
| totalCapacityInGB | Float | 总容量 |
| usedCapacityInGB | Integer | 已用容量 |
| shardNum | Integer | 分片数 |
| flavor | Integer | 单分片容量 |
| qpsWrite | Long | 写流量阈值 |
| qpsRead | Long | 读流量阈值 |
| staleReadable | Boolean | 从角色脏读开关状态（true:打开， false:关闭） |
| forbidWrite | Integer | 禁写标志（0 未禁写， 1 禁写） |
| availabilityZone | String | 可用区 |
| expiredTime | Date | 过期时间 |
