# 获取同步状态

## 获取同步状态

### 接口描述

本接口用于获取实例组中成员建的同步状态。

### 请求结构

Plain Text

```
GET /v{version}/syncGroup/{syncGroupShowId}/syncStatus HTTP/1.1
Host: bcc.bj.baidubce.com
Authorization: authorization string
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | PATH参数 | API版本号。此处值为2。 |
| syncGroupShowId | String | 是 | PATH参数 | 实例组ID。 |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| syncGroupShowId | String | 实例组ID。 |
| syncStatus | List<SyncStatusItem> | 状态列表。 |

  

#### SyncStatusItem

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| memberId | String | 成员集群ID。 |
| status | String | 同步状态。normal为正常，其他为异常。 |

Host: redis.bj.baidubce.com
