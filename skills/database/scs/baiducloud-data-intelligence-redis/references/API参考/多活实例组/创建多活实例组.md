# 创建多活实例组

## 创建多活实例组

### 接口描述

本接口用于创建多活实例组。支持集群跨地域创建实例组。

本接口为v2接口。

**注意事项**

多活实例组仅支持Redis企业集群版，版本为6.0和4.0的集群。

多活实例组中的集群规格配置必须一致。

多活实例组中最多支持添加5个集群。

创建前请确保前置检查全部通过。

### 请求结构

Plain Text

```
POST /v{version}/syncGroup/create HTTP/1.1
Host: redis.bj.baidubce.com
Authorization: authorization string
{
    "syncGroupName": "syncname",
    "members": [
        {
            "memberId": "scs-bj-zzkhtsrlrncf",
            "region": "bj"
        },
        {
            "memberId": "scs-bd-dcyeumpmbars",
            "region": "bd"
        }
    ]
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | PATH参数 | API版本号。此处值为2。 |
| syncGroupName | String | 是 | RequestBody参数 | 多活实例组名称。规则：支持大小写字母、数字以及-\_.等特殊字符，以字母开头，长度6~32位 |
| members | List<Member> | 是 | RequestBody参数 | 多活实例组成员。最多支持5个成员。 |

  

#### Member

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| memberId | String | 集群ID。 |
| region | String | 集群所在地域。 |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| syncGroupShowId | String | 多活实例组ID。 |

  

### 请求示例

Plain Text

```

Host: redis.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2015-08-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    "syncGroupName": "syncname",
    "members": [
        {
            "memberId": "scs-fsh-zzkhtsrlrncf",
            "region": "fsh"
        },
        {
            "memberId": "scs-fsh-dcyeumpmbars",
            "region": "fsh"
        }
    ]
}
```
