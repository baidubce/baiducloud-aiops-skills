# 修改多活实例组名称

## 修改多活实例组名称

### 接口描述

本接口用于修改多活实例组名称。

### 请求结构

Plain Text

```
PUT /v{version}/syncGroup/{syncGroupShowId} HTTP/1.1
Host: redis.bj.baidubce.com
Authorization: authorization string
{
  "groupName": "groupName"
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | PATH参数 | API版本号。此处值为2。 |
| syncGroupShowId | String | 是 | PATH参数 | 多活实例组ID。 |
| groupName | String | 是 | RequestBody参数 | 修改后的实例组名称。 |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

无。

### 请求示例

Plain Text

```
PUT http://redis.fsh.baidubce.com/v2/syncGroup/scs-syncgroup-zyrobvlrgwpl
Host: redis.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2015-08-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    "groupName": "cll1100"
}
```
