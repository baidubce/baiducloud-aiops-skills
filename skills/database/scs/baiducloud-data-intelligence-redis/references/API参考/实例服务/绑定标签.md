# 绑定标签

### 请求说明

* 给实例绑定标签。

### 请求结构

Plain Text

```
PUT /v1/instance/{instanceId}/bindTag HTTP/1.1
Host: redis.{region}.baidubce.com
Authorization: authorization string
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必需 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| instanceId | String | 是 | RequestBody参数 | 虚拟机实例ID |
| changeTags | List<TagModel> | 是 | RequestBody参数 | 待解绑的标签列表 |

### 返回头域

除公共头域，无其它特殊头域。

### 返回参数

无特殊返回参数。

### 请求示例

Plain Text

```
PUT /v1/instance/scs-bj-zpkrihnhtwca/bindTag HTTP/1.1
Host: redis.cd.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/0255cb4f78f140728045b551d6a317ec/2023-08-13T07:46:05Z/1800/host/70268ec1d0491c86e67f345ad3aee4cf7f8924dade9b7f3e2f1a95814a00c129
```

### 返回示例

Plain Text
