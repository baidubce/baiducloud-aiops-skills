# 创建统一读入口

## 创建统一读入口

### 接口描述

本接口用于创建集群的统一读入口。不可重复创建。

本接口为v2接口。

创建完成后可通过查询集群详情接口查看统一读入口地址。

**注意事项**

本接口仅支持Redis社区标准版实例，并且集群存在可用的只读节点。

### 请求结构

Plain Text

```
POST /v{version}/entrance/create/{instanceId} HTTP/1.1
Host: redis.bj.baidubce.com
Authorization: authorization string
{}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | PATH参数 | API版本号。此处值为2。 |
| instanceId | String | 是 | PATH参数 | 要操作的集群ID |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| success | Boolean | 是否创建成功 |
| result | Boolean | 是否创建成功，和success一致 |

  

### 请求示例

Plain Text

```
POST http://redis.bj.baidubce.com/v2/entrance/create/scs-bj-udufxfwaeltv
Host: redis.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2015-08-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{}
```

### 响应示例

Plain Text

```
HTTP/1.1 200 OK
Content-Type: application/json;charset=UTF-8
Date: Wed, 08 Jul 2015 03:28:11 GMT
x-bce-request-id: d8752367-38e8-45e4-b4c7-e53be3137ce5

{
    "success": true,
    "result": true
}
```
