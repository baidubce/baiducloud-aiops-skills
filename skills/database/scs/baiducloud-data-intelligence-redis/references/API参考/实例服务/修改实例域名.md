# 修改实例域名

### 请求说明

* 修改实例域名。

### 请求结构

Plain Text

```
PUT /v1/instance/{instanceId}/renameDomain?clientToken={clientToken} HTTP/1.1
HOST: redis.{region}.baidubce.com
Authorization: authorization string
{
    "domain":"domain"
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| clientToken | String | 是 | URL参数 | 幂等性Token，是一个长度不超过64位的ASCII字符串。 |
| instanceId | String | 是 | URL参数 | 实例ID |
| domain | String | 是 | RequestBody参数 | 新的实例域名。域名命名规范： 1.由小写字母和数字组成； 2.以小写字母开头； 3.长度在3-30之间。 |

  

### 返回头域

除公共头域外，无其它特殊头域。

### 返回参数

无特殊返回参数。

### 请求示例

Plain Text

```
PUT /v1/instance/scs-bj-ykfiztgpxjny/renameDomain HTTP/1.1
HOST: redis.bj.baidubce.com
Content-Type: application/json  
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    "domain":"domain"
}
```

Plain Text

