# 解绑标签

### 请求说明

* 解绑实例上定义的标签。
* 可以同时解绑多个标签。

### 请求结构

Plain Text

```
PUT /v1/instance/{instanceId}/unBindTag HTTP/1.1
Host: redis.{region}.baidubce.com
Authorization: authorization string
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必需 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| instanceId | String | 是 | RequestBody参数 | 虚拟机实例ID |
| changeTags | List | 是 | RequestBody参数 | 待解绑的标签列表，具体数据格式参见下述TagModel |

### 返回头域

除公共头域，无其它特殊头域。

### 返回参数

无特殊返回参数。

### 请求示例

Plain Text

```
PUT /v1/instance/scs-bj-cxisuftlkquj/unBindTag HTTP/1.1
Host: redis.cd.baidubce.com
Content-Type: application/json
Authorization: authorization string
```

### 返回示例

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 1214cca7-4ad5-451d-9215-71cb844c0a50
Content-Type: application/json;charset=UTF-8
```
