# 释放回收站中的实例

### 请求说明

* 从回收站中批量释放Redis实例，释放后实例所使用的物理资源都被收回，相关数据全部丢失且不可恢复。
* 当前版本为V2。

### 请求结构

Plain Text

```
POST /v2/recycler/delete HTTP/1.1
HOST: redis.bj.baidubce.com
Authorization: authorization string
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| instanceIds | List<String> | 是 | RequestBody | 实例Id列表 |

### 返回头域

除公共头域，无其它特殊头域。

### 返回参数

无特殊返回参数。

### 请求示例

Plain Text

```
POST /v2/recycler/delete HTTP/1.1
HOST: redis.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2021-04-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "instanceIds" : [ "scs-bj-arkfmjcblyty" ]
}
```

### 返回示例

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 7869616F-7A68-6977-656E-406261696475
Content-Type: application/json
```

### 错误码

| 错误码 | 错误描述 | HTTP状态码 | 中文解释 |
| --- | --- | --- | --- |
| BadRequest | Bad request parameters or illegal request | 400 | 请求有误 |
| InstanceNotExistException | Instance not found | 404 | 实例未找到或非自己的实例 |
| InstanceDeleteFailed | Instance {instanceId} delete failed | 403 | 删除scs实例失败 |
| ServiceUnavailable | Service is unavailable | 503 | 内部服务器错误 |
