# 修改实例名称

### 请求说明

* 修改实例名称。

### 请求结构

Plain Text

```
PUT /v1/instance/{instanceId}/rename?clientToken={clientToken} HTTP/1.1
HOST: redis.{region}.baidubce.com
Authorization: authorization string
{
    "instanceName":"instanceName"
}
```

### 请求参数

| 参数 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| clientToken | String | 是 | Query参数 | 幂等性Token，是一个长度不超过64位的ASCII字符串。 |
| instanceId | String | 是 | URL参数 | 实例ID |
| instanceName | String | 是 | RequestBody参数 | 新的实例名称。要求： 1. 支持大小写字母、数字以及-\_ /.等特殊字符，必须以字母开头； 2. 长度限制为1-64； 3. 和自己其他实例的名称不重复 |

  

### 返回头域

除公共头域外，无其它特殊头域。

### 返回参数

无特殊返回参数。

}
