# 附录

## Model 对象定义

### InstanceModel

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| instanceId | String | 实例ID |
| instanceName | String | 实例名 |
| instanceStatus | String | [实例状态](#%E5%AE%9E%E4%BE%8B%E7%8A%B6%E6%80%81) |
| isolatedStatus | String | 已隔离:Isolated(实例在回收站内) |
| clusterType | String | 引擎类型为Redis，取值：集群: “cluster” 主从:“master\_slave”，default: 主从 |
| engine | String | 引擎类型，redis,memcache |
| engineVersion | String | 引擎版本 |
| vnetIp | String | 私网IP |
| domain | String | 域名 |
| port | String | 链接端口 |
| instanceCreateTime | Datetime | 实例创建时间 |
| instanceExpireTime | Datetime | 实例到期时间 |
| capacity | Float | 总容量，单位GB |
| usedCapacity | double | 已用容量，单位GB |
| paymentTiming | String | 付费方式。预付费：Prepaid，后付费：Postpaid |
| zoneNames | List<String> | 可用区list |
| orderStatus | String | 预转后、后转预的标记。- to\_postpay: 预付费转后付费 - to\_prepay: 后付费转预付费 |
| deployIdList | List<String> | 集群绑定的部署集ID列表。 |

## 状态编码定义

### 实例状态

| 状态值 | 描述 |
| --- | --- |
| Creating | 创建中 |
| Running | 运行中 |
| Rebooting | 实例重启中 |
| Pausing | 暂停中 |
| Paused | 已欠费 |
| Deleted | 已释放 |
| Deleting | 释放中 |
| Failed | 已失败 |
| Modifying | 配置变更中 |
| Modifyfailed | 配置变更失败 |
| Backuping | 备份中 |
| Aztransforming | 转换可用区 |
| Expire | 已到期 |
| Flushing | 清空实例 |
| Flush failed | 清空失败 |

## 订单信息定义

### Billing

| 状态 | 类型 | 描述 |
| --- | --- | --- |
| paymentTiming | String | 付费方式： 预付费：Prepaid，后付费：Postpaid |
| reservation | Reservation | 保留信息，支付方式为后支付时不需要设置，预支付时必须设置 |

### Reservation

| 状态 | 类型 | 描述 |
| --- | --- | --- |
| reservationLength | int | 时长，[1,2,3,4,5,6,7,8,9,12,24,36] |
| reservationTimeUnit | String | 时间单位，Month，当前仅支持按月 |
