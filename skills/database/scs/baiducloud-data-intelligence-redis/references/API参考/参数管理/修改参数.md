# 修改参数

### 请求说明

* 修改redis实例参数值。

### 请求结构

Plain Text

```
PUT /v1/instance/{instanceId}/parameter  clientToken={clientToken} HTTP/1.1
Host: redis.{region}.baidubce.com
Authorization: authorization string
{
  "parameter": {
    "name": "name",
    "value": "value"
   }
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| clientToken | String | 是 | URL参数 | 幂等性Token，是一个长度不超过64位的ASCII字符串 |
| instanceId | String | 是 | URL参数 | 实例Id |
| parameter | instanceParam | 是 | RequestBody参数 | 需要修改的参数 |

  

#### instanceParam参数信息

| 参数名称 | 类型 | 是否必须 | 描述 |
| --- | --- | --- | --- |
| name | String | 是 | 参数名称 |
| value | String | 是 | 设置参数值 |

  

### 返回头域

除公共头部，无其它特殊头部。

### 返回参数

无特殊返回参数。

### 请求示例

Plain Text

```
PUT /v1/instance/scs-bj-ykfiztgpxjny/parameter HTTP/1.1
HOST: redis.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "parameter": {
    "name": "appendonly",
    "value": "no"
   }
}
```
