# 应用参数模版

### 请求说明

应用参数模版到实例。

### 请求结构

Plain Text

```
POST /v2/template/apply/{templateShowId} HTTP/1.1
Host: redis.{region}.baidubce.com
Authorization: authorization string
{
    "rebootType" : rebootType,
    "extra" : "extra",
    "cacheClusterList" : [ {
        "cacheClusterShowId" : "cacheClusterShowId",
        "region" : "region"
    } ],
    "parameters" : [ {
        "confName" : "confName",
        "confModule" : confModule,
        "confValue" : "confValue0,confValue1",
        "confType" : confType
    } ]
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| templateShowId | String | 否 | URL参数 | 模版ID |
| extra | String | 是 | RequestBody参数 | 是否有额外的修改（0：无；1：有），没有修改的参数不需要传parameters |
| cacheClusterList | List<[cacheClusterShowIdItem](#cacheclustershowiditem)> | 否 | RequestBody参数 | 实例ID集合 |
| rebootType | Integer | 否 | RequestBody参数 | 是否需要重启（0 不重启 1 维护时间重启 2 立即重启 如果是热活的主集群的话不可以重启） |
| parameters | List <[Parameters](#parameters)> | 否 | RequestBody参数 | 参数模版中需要修改的参数，extra=1时有效 |

  

#### Parameters

| 参数名称 | 类型 | 是否必选 | 描述 |
| --- | --- | --- | --- |
| confName | String | 是 | 参数名称（可参考系统模版） |
| confValue | String | 是 | 参数值（可修改对应的值，可参考系统模版在confRange的允许范围内修改） |
| confType | Integer | 是 | 参数类型（可参考系统模版） |
| confModule | Integer | 是 | 可参考系统模版 |

#### cacheClusterShowIdItem

| 参数名称 | 类型 | 是否必选 | 描述 |
| --- | --- | --- | --- |
| region | String | 是 | 实例所在地域 |
| cacheClusterShowId | String | 是 | 实例ID |

### 返回头域

除公共头域外，无其它特殊头域。

### 返回参数

无特殊返回参数。
