# 参数模版删除参数

### 接口说明

修改参数模版名称。

### 请求结构

Plain Text

```
POST /v2/template/deleteParams/{templateShowId} HTTP/1.1
Host: redis.{region}.baidubce.com
Authorization: authorization string
{
    parameters: [
        "parameters0"，"parameters1"
    ]
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| templateShowId | String | 是 | URL参数 | 待查询的参数模版ID |
| parameters | List<String> | 是 | RequestBody参数 | 要删除的参数名称集合 |

  

### 返回头域

除公共头域外，无其它特殊头域。

### 返回参数

无特殊返回参数。

### 请求示例

Plain Text

```
POST /v2/template/deleteParams/scs-tmpl-dycgmxbxlbow
HOST: redis.bj.baidubce.com
Content-Type: application/json 
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    parameters: [
        "appendonly"
    ]
}
```
