# 功能更新记录

## 2020-11-23

* 首次发布：上线账户余额查询接口，提供新的余额查询方式

## 2020-03-04

* 接口更新：资源月账单明细列表查询接口，提供更丰富的查询方式，新增支持按天查询资源月账单详情。

## 2020-02-12

* 接口更新：资源月账单明细列表查询接口，提供更丰富的字段返回值，包括折扣用量。

## 2019-06-28

* 接口更新：资源月账单明细列表查询接口，提供更丰富的字段返回值，包括账单折扣详情、应付金额、优惠金额等。

## 2019-04-15

* 首次发布：上线资源月账单明细列表查询接口，包括多用户控制访问，企业组织财务管理的主子账户管理查询功能。
