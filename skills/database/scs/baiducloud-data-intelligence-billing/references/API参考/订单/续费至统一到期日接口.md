# 续费至统一到期日接口

## 续费至统一到期日相关接口

## 设置统一到期日unionexpireday/update接口

### 接口描述

更新统一到期日，目前适用于云服务器BCC、云磁盘CDS、弹性公网IP。

### 权限说明

请求发起人需要具有合法的AccessKeyID和SecretAccessKey才能发起请求，请参考[鉴权认证](/doc/Reference/s/Njwvz1wot)。

### 注意事项

如果请求中没有用户验证信息（即匿名访问），返回403 Forbidden，错误信息：AccessDenied。
下单请求 QPS 在100以内。

### 请求路径

/v1/finance/unionexpireday/update

### 请求方式

POST application/json

### 请求参数

| 名称 | 类型 | 参数位置 | 描述 | 是否必须 |
| --- | --- | --- | --- | --- |
| queryAccountId | String | body参数 | 账户 id，可以传入自己及下级账号的续费资源。不传则设置当前账户的资源。账户 id 需要和待续费资源的 id 一致 | 否 |
| unionExpireDay | INT | body参数 | 当前统一到期日设置只支持未过期BCC、CDS、EIP实例，已过期实例无法对齐统一到期日。设置完成后，可在续费时对齐设置的统一到期时间 日期范围：每月 1 号至 28 号 | 是 |

### 请求示例

Plain Text

```
{
    "queryAccountId": "账户ID，可传自己或下级账户，不传时会取当前登录账户",
    "unionExpireDay": 20
}
```

### 返回示例

Plain Text

```
{
    "success": true,  /* true：请求成功，false：请求失败 */
    "accountId": "账户ID，若查询子账户，则为主账户ID",
    "loginName": "账户登录名，若查询子账户，则为主账户登录名",
    "subAccountId": "子账户ID",
    "subLoginName": "子账户登录名",
    "ouName": "子账户所在组织单元名"
}
```

## 查询统一到期日unionexpireday/get接口

### 接口描述

查询资源的统一到期日，目前适用于云服务器BCC、云磁盘CDS、弹性公网IP。

### 权限说明

请求发起人需要具有合法的AccessKeyID和SecretAccessKey才能发起请求，请参考[鉴权认证](/doc/Reference/s/Njwvz1wot)。

### 注意事项

如果请求中没有用户验证信息（即匿名访问），返回403 Forbidden，错误信息：AccessDenied。
下单请求 QPS 在100以内。

### 请求路径

/v1/finance/unionexpireday/get

### 请求方式

GET application/json

### 请求参数

| 名称 | 类型 | 参数位置 | 描述 | 是否必须 |
| --- | --- | --- | --- | --- |
| queryAccountId | String | param参数 | 账户 id，可以传入自己及下级账号的续费资源。不传则查当前账户的信息 | 否 |

### 请求示例

Plain Text

```
curl http://host:port/v1/finance/unionexpireday/get?queryAccountId=xxxx
```

### 返回示例

Plain Text

```
{
    "unionExpireDay": 0,  /* 0：代表用户未设置统一到期日，1～28为用户设置的统一到期日 */
    "accountId": "账户ID，若查询子账户，则为主账户ID",
    "loginName": "账户登录名，若查询子账户，则为主账户登录名",
    "subAccountId": "子账户ID",
    "subLoginName": "子账户登录名",
    "ouName": "子账户所在组织单元名"
}
```
