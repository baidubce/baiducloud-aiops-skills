### ResourceChargeItemBill

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| vendor | String | 供应商名称，默认为百度智能云 |
| serviceType | String | 产品名 |
| serviceTypeName | String | 产品中文名 |
| productType | String | 计费类型：prepay/postpay，分别表示预付费/后付费，目前只有后付费 |
| region | String | 区域 |
| instanceId | String | 资源长ID |
| shortId | String | 资源短ID |
| startTime | String | 计费项账单开始时间（后付费），utc时间 |
| endTime | String | 计费项账单结束时间（后付费），utc时间 |
| configurationCH | String | 产品中文配置 |
| chargeItem | String | 后付费计费项英文名 |
| chargeItemDesc | String | 后付费计费项中文名 |
| amount | String | 用量 |
| amountUnit | String | 用量单位 |
| discountAmount | String | 折扣用量 |
| unitPrice | String | 产品单价 |
| pricingUnit | String | 价格单位 |
| catalogPrice | BigDecimal | 原价 |
| promotionPrice | BigDecimal | 价格优惠 |
| originPrice | BigDecimal | 账单金额 |
| financePrice | BigDecimal | 应付金额 |
| couponPrice | BigDecimal | 代金券金额 |
| discountCouponPrice | BigDecimal | 折扣券金额 |
| discountPrice | BigDecimal | 折扣金额 |
| cashEquivalentCouponPrice | BigDecimal | 现金折扣券金额 |
| sysGold | BigDecimal | 销账金额 |

注：  
1 String类型的字段若无实际值，默认赋值"/"。  
2 为与[企业组织财务管理](/doc/Reference/s/ejwvz2azx)逻辑保持一致，加入财务圈的子账户单独查询资源月账单详情时，除代金券金额和折扣券金额外的金额字段会默认赋值为0。  
3 金额相关公式：  
应付金额 = 现金支付金额 + 返点支付金额 + 账期未还金额 + 账期退款金额 + 欠款金额  
优惠金额 = 代金券抵扣金额 + 折扣券抵扣金额 + 折扣金额 + 销账金额  
原价 = 应付金额 + 优惠金额 + 价格优惠
