# 资源月账单

## GetResourceMonthBill接口

### 接口描述

分页获取资源月账单详情。  
[企业组织财务管理](/doc/Reference/s/ejwvz2azx)中的主账户可以查询子账户的账单详情。  
加入财务圈的子账户会屏蔽代金券之外的其他金额。子用户要发起该请求，需要具有[多用户访问控制](/doc/Reference/s/ujwvz2bpq)的管理员权限或者FCFullControlPolicy多用户访问控制策略管理权限。

默认接口请求频率限制：20次/秒。

### 权限说明

请求发起人需要具有合法的AccessKeyID和SecretAccessKey才能发起请求，请参考[鉴权认证](/doc/Reference/s/Njwvz1wot)。

### 注意事项

如果请求中没有用户验证信息（即匿名访问），返回`403 Forbidden`，错误信息：`AccessDenied`。

### 请求结构与示例

Plain Text

```
 GET /v{version}/bill/resource/month?month={month}&productType={productType}&serviceType={serviceType}&queryAccountId={queryAccountId}&pageNo={pageNo}&pageSize={pageSize} HTTP/1.1 
 Host: billing.baidubce.com 
 ContentType: application/json
 Authorization: authorization string
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 名称 | 类型 | 参数位置 | 描述 | 是否必须 |
| --- | --- | --- | --- | --- |
| month | String | Query参数 | 查询账单所属月份，格式yyyy-MM，例：2019-02。若查询当月，仅支持查询截止昨日的账单。 | 可选 |
| beginTime | String | Query参数 | 按天查询账单所属时间区间最早时间，格式yyyy-MM-dd，例：2019-02-01 | 可选 |
| endTime | String | Query参数 | 按天查询账单所属时间区间最晚时间，格式yyyy-MM-dd，例：2019-02-18。若按天查询参数非空，优先返回按天查询的结果；按天查询时间区间不支持跨月；按天查询可以查询本月今天之前的账单；若需查询昨日的账单，为保证数据准确处理完毕，请当日十点后查询。 | 可选 |
| granularity | String | Query参数 | 账单聚合周期，取值范围：null/day，不传默认为空（null）。day：指定查询时间内，按天分别对账单明细进行聚合，多天账单会按天粒度拆分为多条；为空或null：按查询时间对账单进行聚合，多天账单会汇总为一条。 | 可选 |
| productType | String | Query参数 | 计费类型：prepay/ postpay，分别表示预付费/后付费 | 必须 |
| serviceType | String | Query参数 | 产品类型，例：BCC，BOS等 | 可选 |
| instanceId | String | Query参数 | 查询资源的长ID或短ID，例：i-NF06VjgG | 可选 |
| queryAccountId | String | Query参数 | 查询账户ID，只有企业组织（或者虚商）的主账户可以查询加入财务圈（或者虚商组织）的子账户账单，否则会提示AccessDenied | 可选 |
| showControversial | boolean | Query参数 | 是否展示争议账单信息。true 表示展示争议账单信息，即账单被标记为争议账单的标记、时间、确认的时间等字段；false 表示不展示争议账单的信息（默认值）。 | 可选 |
| displaySystemUnit | String | Query参数 | 进制单位，用于展示bps/bytes计费项的单位转换，可选枚举值B/M/G，不传或传空为默认为系统自动的进制。 | 可选 |
| pageNo | int | Query参数 | 分页查询的页数，默认为1 | 可选 |
| pageSize | int | Query参数 | 每页包含的最大数量，最大数量通常不超过100，缺省值为20。 | 可选 |

> 说明：一次请求最多返回100个账单的信息。  
> 注意：month和beginTime & endTime必须二选一。

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| billMonth | String | 按月查询账单所属月份，格式yyyy-MM，例：2019-02 |
| beginTime | String | 按天查询账单所属时间区间最早时间，格式yyyy-MM-dd，例：2019-02-01 |
| endTime | String | 按天查询账单所属时间区间最晚时间，格式yyyy-MM-dd，例：2019-02-18 |
| accountId | String | 当前账户不是财务圈子账户时，返回当前账户accountId；是财务圈子账户时，返回当前账户主账户的accountId |
| loginName | String | 当前账户不是财务圈子账户时，返回当前账户的登录名；是财务圈子账户时，返回当前账户主账户的登录名 |
| subAccountId | String | 当前账户不是财务圈子账户时，返回"/"；是财务圈子账户时，返回当前账户的accountId |
| subLoginName | String | 当前账户不是财务圈子账户时，返回"/"；是财务圈子账户时，返回当前账户的登录名 |
| ouName | String | 当前账户不是财务圈子账户时，返回"/"；是财务圈子账户时，返回当前账户所在组织单元的单元名 |
| pageNo | Integer | 分页查询编号 |
| pageSize | Integer | 分页查询分页大小 |
| totalCount | Integer | 当前查询条件总条目 |
| bills | List< [ResourceMonthInstanceBill](/doc/Finance/s/Bjxg02xim#resourcemonthinstancebill) > | 资源月账单列表 |
