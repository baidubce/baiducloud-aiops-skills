# 计费项账单

## GetResourceChargeItemBillList接口

### 接口描述

分页获取后付费资源计费项账单详情。  
[企业组织财务管理](/doc/Reference/s/ejwvz2azx)中的主账户可以查询子账户的账单详情。  
加入财务圈的子账户会屏蔽代金券之外的其他金额。子用户要发起该请求，需要具有[多用户访问控制](/doc/Reference/s/ujwvz2bpq)的管理员权限或者FCFullControlPolicy多用户访问控制策略管理权限。

> 说明：
>
> * 默认接口请求频率限制：20次/秒。
> * 当日10点后可查询前一日的账单。

### 权限说明

请求发起人需要具有合法的AccessKeyID和SecretAccessKey才能发起请求，请参考[鉴权认证](/doc/Reference/s/Njwvz1wot)。

### 注意事项

如果请求中没有用户验证信息（即匿名访问），返回`403 Forbidden`，错误信息：`AccessDenied`。

### 请求结构

Plain Text

```
POST /v{version}/bill/resource/chargeitem HTTP/1.1
Host: billing.baidubce.com
Authorization: authorization string
{
    "billMonth": "2023-03",
    "serviceType" : "BCC",
    "queryAccountId" : accountId,
    "pageNo": 1,
    "pageSize": 100
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| billMonth | String | 否 | RequestBody参数 | 按月查询账单所属月份，格式yyyy-MM，例：2019-02 |
| beginTime | String | 否 | RequestBody参数 | 按天查询账单所属时间区间最早时间，格式yyyy-MM-dd，例：2019-02-01 |
| endTime | String | 否 | RequestBody参数 | 按天查询账单所属时间区间最晚时间，格式yyyy-MM-dd，例：2019-02-18。若按天查询参数非空，优先返回按天查询的结果；按天查询时间区间不支持跨月；按天查询可以查询今天截止上一小时的账单； |
| serviceType | String | 否 | RequestBody参数 | 产品类型，例：BCC，BOS等 |
| queryAccountId | String | 否 | RequestBody参数 | 查询账户ID，企业组织/虚商的主账户可以查询加入财务圈的子账户账单，其他查询场景会提示AccessDenied |
| pageNo | int | 否 | RequestBody参数 | 分页查询的页数，默认为1 |
| pageSize | int | 否 | RequestBody参数 | 每页包含的最大数量，最大数量不超过100，缺省值为100。 |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| billMonth | String | 按月查询账单所属月份，格式yyyy-MM，例：2019-02 |
| beginTime | String | 按天查询账单所属时间区间最早时间，格式yyyy-MM-dd hh:mm:ss，例：2019-02-01 00:00:00 |
| endTime | String | 按天查询账单所属时间区间最晚时间，格式yyyy-MM-dd hh:mm:ss，例：2019-02-01 00:00:00 |
| accountId | String | 当前账户不是财务圈子账户时，返回当前账户accountId；是财务圈子账户时，返回当前账户主账户的accountId |
| loginName | String | 当前账户不是财务圈子账户时，返回当前账户的登录名；是财务圈子账户时，返回当前账户主账户的登录名 |
| subAccountId | String | 当前账户不是财务圈子账户时，返回"/"；是财务圈子账户时，返回当前账户的accountId |
| subLoginName | String | 当前账户不是财务圈子账户时，返回"/"；是财务圈子账户时，返回当前账户的登录名 |
| ouName | String | 当前账户不是财务圈子账户时，返回"/"；是财务圈子账户时，返回当前账户所在组织单元的单元名 |
| pageNo | Integer | 分页查询编号 |
| pageSize | Integer | 分页查询分页大小 |
| totalCount | Integer | 当前查询条件总条目 |
| bills | List< [ResourceChargeItemBill](/doc/Finance/s/Bjxg02xim#resourcechargeitembill) > | 资源计费项账单列表 |
