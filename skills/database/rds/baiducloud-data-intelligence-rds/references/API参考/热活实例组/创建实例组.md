# 创建实例组

**接口描述**

本接口用于创建实例组。

本接口为v1接口。

**请求结构**

Plain Text

```
POST /v{version}/instance/group HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
{
 "name":"name",
 "leaderId":"leaderId"
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 示例值 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- | --- |
| version | Integer | 是 | 1 | URL参数 | API 版本号 |
| name | String | 是 | group-name | RequestBody参数 | 实例组名称 |
| leaderId | String | 是 | rds-0ftLecci | RequestBody参数 | 实例ID |

  

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| result | Integer | 成功：200；失败：其余状态码 |

**请求示例**

Plain Text

```
POST http://rds.bj.baidubce.com/v1/instance/group HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2023-09-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "name":"group-name",
  "leaderId":"rds-0ftLecci"
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
Content-Type: application/json
x-bce-request-id: d8752367-38e8-45e4-b4c7-e53be3137ce5
{
  "result": 200
}
```
