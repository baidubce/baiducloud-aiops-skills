# 小版本前置检查

## 接口描述

本接口用于实例加入热活组的小版本前置检查。

本接口为v1接口。

## 请求结构

Plain Text

```
POST /v{version}/instance/group/checkVersion HTTP/1.1
Host: rds.bj.baidubce.com
Content-Type: application/json
Authorization: authorization string
{
   "leaderId": "leaderId",
   "followerId": "followerId"
}
```

## 请求头域

除公共头域外，无其它特殊头域。

## 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | Path参数 | API版本号，此处值为1 |
| leaderId | String | 是 | RequestBody参数 | 主地域的主实例ID |
| followerId | String | 是 | RequestBody参数 | 从地域的主实例ID |

  

## 响应头域

除公共头域外，无其它特殊头域。

## 响应参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| result | Bool | 成功：true；失败：false |

  

## 请求示例

Plain Text

```
POST http://rds.bj.baidubce.com/v1/instance/group/checkVersion
Host: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2015-08-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    "leaderId":"rds-fOtDrTd6",
    "followerId":"rds-WCUaZbKI"
}
```
