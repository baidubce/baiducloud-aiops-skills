# 实例开机

## 实例开机

### 接口描述

本接口用于恢复回收站中的实例，将回收站中的实例更新成正常实例，适用于操作单个实例开机与批量实例的开机。

本接口为v1接口。

**注意事项**

注：目前批量操作的实例个数上限是三个实例

### 请求结构

Plain Text

```
PUT /v{version}/instance/recycler/recover HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
{
    "instanceIds": []
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | Path参数 | API 版本号，此处值为1 |
| instanceIds | List String | 是 | RequestBody参数 | 存储请求开机的实例ID的数组 |

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

无特殊返回参数

### 请求示例

Plain Text

```
PUT http://rds.bj.baidubce.com/v1/instance/recycler/recover
Host: rds.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2015-08-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "instanceIds": [
    "rds-aaaa",
    "rds-bbbb"
  ]
}
```

HTTP/1.1 200 OK
Content-Type: application/json;charset=UTF-8
