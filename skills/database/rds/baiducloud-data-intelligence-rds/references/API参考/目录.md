# 目录

## 概述

欢迎使用百度智能云的核心产品——云数据库 RDS (Relational Database Service)。云数据库 RDS Open API 现已全量开放，您可直接使用。

您可以使用本文档介绍的API 对云数据库 RDS 服务进行灵活的操作。

如果您是初次调用百度智能云产品的API，可以观看[API入门视频指南](https://cloud.baidu.com/doc/APIGUIDE/index.html)，快速掌握调用API的方法。

云数据库 RDS API 现提供下列接口类型：

| 接口类型 | 接口描述 |
| --- | --- |
| [实例管理](/doc/RDS/s/Dka65m22p) | 实例 Instance 是一个关系型数据库实例，通过实例管理API 提供的接口可以支持的操作有：创建主实例、创建只读实例、创建代理实例、实例列表、实例详情、变更配置、重启、释放、修改名称、开关公网访问、修改同步方式、修改域名、修改备份策略。 |
| [账号管理](/doc/RDS/s/vkyvagetm) | 账号 Account 是一个云数据库 RDS 实例访问账号，其接口支持的操作有：创建账号、账号列表、账号详情、修改备注、修改密码、修改权限、删除账号。 |
| [备份管理](https://cloud.baidu.com/doc/RDS/s/Kkyvagexl) | 备份 Backup 是一个云数据库 RDS 实例的数据镜像备份，API 提供镜像查看、下载、创建等操作。 |
| [安全管理](/doc/RDS/s/8kyvagf28) | 安全管理 security 是一个云数据库 RDS 实例的安全管理，API 提供更新白名单、查询白名单等操作。 |
| [参数管理](https://cloud.baidu.com/doc/RDS/s/1ka65tdrg) | 云数据库 RDS 实例内部参数管理，API 提供获取参数列表、参看修改历史、修改参数值等操作。 |
| [日志管理](https://cloud.baidu.com/doc/RDS/s/Pkyvagf07) | 云数据库 RDS 实例内部日志管理，API 提供慢日志管理任务列表、查询慢日志下载任务详情和获取慢日志详情等操作。 |
| [数据库管理](https://cloud.baidu.com/doc/RDS/s/elbu845nz) | 数据库管理 Database 是一个云数据库 RDS 实例数据库，API 提供修改数据库端口等操作。 |
| [任务管理](https://cloud.baidu.com/doc/RDS/s/Alenynogo) | 任务管理 Task 是一个云数据库 RDS 实例的任务管理，API 提供查询任务列表等操作。 |
| [回收站管理](https://cloud.baidu.com/doc/RDS/s/olcshszav) | 回收站管理 Recycler 是一个云数据库 RDS 实例的回收站管理，API 提供查询回收站实例列表、实例开机、删除单个实例等操作。 |
| [热活实例组](/doc/RDS/s/6lgsswx8y) | 热活实例组 Group API 提供创建实例组、查询实例组列表、实例组详情等操作。 |
| [版本管理](https://cloud.baidu.com/doc/RDS/s/Dlg1zj2g5) | 版本管理 Version API 提供查看实例允许升级的小版本列表、实例升级小版本等操作。 |
| [SmartDBA](https://cloud.baidu.com/doc/RDS/s/nlbahemhc) | SmartDBA API 提供开通慢SQL诊断等操作。 |
| [Performance](https://cloud.baidu.com/doc/RDS/s/3kyvagf3r) | Performance API 提供Kill会话、查询innodbstatus快照数据、查询processlist快照数据、询事务列表、查询连接列表等操作。 |
| [其它](/doc/RDS/s/zka65zqz2) | 通过该部分提供的接口，可以快速获取可用区列表和获取子网列表以及查看和更新白名单。 接口：获取可用区列表、获取子网列表、查看白名单、更新白名单。 |
