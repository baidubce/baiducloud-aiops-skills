# 实例升级小版本

**接口描述**

本接口用于对实例发起小版本升级。

本接口为v1接口。

**请求结构**

Plain Text

```
PUT /v{version}/rds/instance/{instanceId}?upgradeMinorVersion HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
{
  "targetMinorVersion": "5.7.38",
  "effectiveTime": "immediate"
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | API版本号。此接口值为1 |
| instanceId | String | 是 | URL参数 | 实例ID |
| upgradeMinorVersion | String | 是 | URL参数 | 固定值，不可更改 |
| targetMinorVersion | String | 是 | RequestBody参数 | 要升级的目标小版本。此值可通过查询当前实例支持升级的小版本列表拿到 |
| effectiveTime | String | 是 | RequestBody参数 | 小版本升级的切换时间，支持immediate和timewindow，默认为immediate。immediate表示立即切换 timewindow表示时间窗口切换 |

  

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

无

**请求示例**

Plain Text

```
PUT http://rds.bj.baidubce.com/v1/rds/instance/rds-RX7mPB1o?upgradeMinorVersion
Host: rds.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2015-08-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "targetMinorVersion": "5.7.38",
  "effectiveTime": "immediate"
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
Content-Type: application/json;charset=UTF-8
x-bce-request-id: d8752367-38e8-45e4-b4c7-e53be3137ce5
```
