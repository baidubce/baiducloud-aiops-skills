# 查看实例允许升级的小版本列表

**接口描述**

* 本接口用于查看实例允许升级的小版本列表。
* 本接口为v1接口。

**请求结构**

Plain Text

```
GET /v{version}/rds/instance/{instanceId}/upgradeMinorVersionList?locale=en-us HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | API版本号。此接口值为1 |
| instanceId | String | 是 | URL参数 | 实例ID |
| locale | String | 否 | URL参数 | 用于判断国际化异常提示信息。当取值为en-us异常提示为英文，取值为zh-cn 异常提示为中文。默认是中文 |

  

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| rdsMinorVersionList | List<RdsMinorVersionList> | 实例可升级的小版本列表信息 |

  

**RdsMinorVersionList**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| dbVersion | String | 数据库版本 |
| minorVersion | String | 数据库小版本 |
| rdsMinorVersion | String | 小版本名称 |
| featureDescription | String | 小版本的功能描述 |

**请求示例**

Plain Text

```
GET http://rds.bj.baidubce.com/v1/rds/instance/rds-RX7mPB1o/upgradeMinorVersionList=en-us
Host: rds.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2015-08-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
```
