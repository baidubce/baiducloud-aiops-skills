# 修改连接信息

**接口说明**

修改连接信息。

**注意事项**

建议InstanceDict对象提交的主机信息、端口、内网和外网IP的信息不一样否则，有可能修改不成功。

**请求结构**

Plain Text

```
PUT /v{version}/rds/{sourceAppId}/rogroup/{roGroupId}/updateEndpoint  HTTP/1.1
HOST: rds.bj.baidubce.com
Authorization: authorization string
{
"roGroupName":"testname",
"endpoint":{
"address":"address",
"port":port,
"inetIp":"1inetIp",
"vnetIp":"vnetIp"
},
"leastAppAmount":leastAppAmount,
"delayThreshold":delayThreshold
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | API 版本号 |
| sourceAppId | String | 是 | URL参数 | 指定实例ID |
| roGroupId | String | 是 | URL参数 | 只读组ID |
| roGroupName | String | 否 | RequestBody参数 | 只读组名称 |
| endpoint | InstanceDict | 是 | RequestBody参数 | 连接信息 |
| leastAppAmount | Integer | 否 | RequestBody参数 | 组内最少保留实例数目，取值为0~5之间的整数。默认为1 |
| delayThreshold | Integer | 否 | RequestBody参数 | 延迟阈值，取值为大于等于0的整数。默认为10 |

**InstanceDict（修改的参数值不能和已经运行的参数值一样）**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| port | Integer | 否 | InstanceDict 对象内 | 端口范围：1024 - 65535 |
| vnetIp | String | 否 | InstanceDict 对象内 | 内网IP |
| inetIp | String | 否 | InstanceDict 对象内 | 外网IP |
| address | String | 是 | InstanceDict 对象内 | address由小写字母、数字或者-组成， 以小写字母开头，长度在3-30之间；不包含后缀 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无特殊返回参数。

**请求示例**

Plain Text

```
PUT /v{version}/rds/{sourceAppId}/rogroup/{roGroupId}/updateEndpoint HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/rdsak/2016-07-03T06:13:13Z/1800/x-bce-date/{signature}
 {
    "roGroupName":"testname",
    "endpoint":{
    "address":"rdsmrg",
    "port":3306,
    "inetIp":"113.24.230.172",
    "vnetIp":"192.168.0.62"
    },
    "leastAppAmount":5,
    "delayThreshold":10
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 7869616F-7A68-6977-656E-406261696475
Content-Type: application/json
```
