# 展示主实例关联的只读组列表

**接口说明**

展示主实例关联的只读组列表。

**请求结构**

Plain Text

```
GET /v{version}/rds/{sourceAppId}/rogroup/list  HTTP/1.1
HOST: rds.bj.baidubce.com
Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | API 版本号 |
| sourceAppId | String | 是 | URL参数 | 指定实例ID |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| roGroupId | String | 只读组ID |
| status | String | 只读组状态 |
| roGroupName | String | 只读组名称 |
| endpoint | Dict | 只读组连接信息 |
| sourceAppId | String | 指定实例ID |
| instanceShortId | String | 实例短ID |
| appAmount | String | 只读组绑定只读实例数量 |
| appList | AppList | 只读组详情 |
| vpcId | String | VPC ID |
| subnetId | String | 子网ID |
| enableDelayOff | Boolean | 是否启用延迟剔除。true：启用，false：未启用 |
| delayThreshold | Integer | 延迟阈值 |
| leastAppAmount | Integer | 组内最少保留实例数目 |
| balanceReload | Boolean | 是否启用重新负载均衡开关,true：启用，false：未启用。 |
| bgwGroupExclusive | Boolean | 分配到共享集群还是专属集群,true：共享集群、false专属集群。 |
| bgwGroupId | String | 集群ID |
| vpcVo | SimpleVpcVo | vpcVo 对象 |
| subnetVo | SubnetVo | 子网对象 |
| region | String | 地域。如：bj、cd |

**Dict 对象**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| entryHost | String | 主机 |
| entryPort | Integer | 端口 |
| vnetIp | String | 内网IP |
| inetIp | String | 公网IP |
| eipStatus | String | 公网状态。closed：关闭、online：开通 |

**AppList 对象**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| vpcId | String | vpcID |
| shortId | String | vpc短ID |
| name | String | vpc名称 |
| cidr | String | Ipv4地址Ipv4地址 |
| status | Integer | 子网状态 0表示可用、1表示创建中、大于等于2时表示不可用 |
| createTime | Date | 创建时间。格式：yyyy-MM-dd'T'HH:mm:ss'Z'。 |
| description | String | 子网描述。 |
| defaultVpc | Boolean | 是否默认子网。 true：有、false：没有；默认false |
| ipv6Cidr | String | Ipv4地址 |
| auxiliaryCidr | List<String> | Ipv4地址（vpc辅网络） |
| relay | Boolean | 是否开启replay。true：开启、false：未开启；默认false |

**SimpleVpcVo**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| name | String | vpc名称 |
| subnetId | String | 子网ID |
| az | String | 逻辑区域名称，zone+大些字母，例如zoneE |
| cidr | String | Ipv4地址 |
| ipv6Cidr | String | Ipv6地址 |
| vpcId | String | vpcID |
| vpcShortId | String | vpc短ID |
| subnetUuid | String | 子网唯一序列号 |
| accountId | String | 账号 |
| subnetType | Intger | 设备类型 BCC(1), BBC（2）, BCC\_NAT（3）,BBC\_NAT（4） |
| type | Intger | 网络类型 未分配（-1） VPC(0),SUBNET(1),ROUTE\_TABLE(2), ROUTE\_RULE(3), ACL\_RULE(4), ENI(5); |
| createdTime | String | 创建时间 年-月-日 时:分:秒 |
| updatedTime | String | 更新时间 年-月-日 时:分:秒 |
| description | String | 描述 |
| shortId | String | 子网 短ID |
| usedIps | String | 使用连接数 |
| totalIps | String | 总数连接数 |
| tags | List<Tag> | 分组标签 |
| zoneName | String | 区域名称 |

Plain Text

```
GET v1/rds/rdsmap2ojzds5od/rogroup/list HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/rdsak/2016-07-03T06:13:13Z/1800/x-bce-date/{signature}
```
