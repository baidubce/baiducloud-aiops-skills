# 更新实例名称

**接口说明**

本接口用于更新实例名称，版本号为v1

**请求结构**

Plain Text

```
PUT /v{version}/instance/{instanceId}?rename HTTP/1.1
HOST: rds.bj.baidubce.com
Authorization:authorization string
{
  "instanceName":"instanceName"
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 参数类型 | 是否必须 | 参数位置 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | 1 | API版本号 |
| instanceId | String | 是 | URL参数 | rds-Z47RwKjh | 实例ID |
| instanceName | String | 是 | requestBody参数 | instance\_1 | 实例名称。 1）用户自定义实例名。 2）允许小写字母、数字。 3）长度限制为1~64。 |

  

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

无

**请求示例**

Plain Text

```
PUT /v1/instance/rds-Z47RwKjh?rename HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
 "instanceName":"instance_1"
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
Content-Type: application/json;charset=UTF-8
x-bce-request-id: d8752367-38e8-45e4-b4c7-e53be3137ce5
```
