# 集群状态检查

### 接口描述

本接口用于检查实例所在集群的状态。

本接口为v1接口。

**注意事项**

本接口适用于MySQL引擎类型的实例，接口允许传入双机高可用版实例，允许传入MySQL引擎类型的只读实例。

### 请求结构

Plain Text

```
GET /v{version}/instance/{instanceId}/status HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | PATH参数 | API版本号，此处值为1。 |
| instanceId | String | 是 | PATH参数 | 要检查的实例ID。 |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| clusterStatus | String | 用于描述集群状态，有两种取值。normal 集群状态正常；abnormal 集群状态不正常。 |
| checkList | CheckStatusResponse | 检查项，每项中：Yes表示检查通过，No表示检查不通过。所有项检查通过，clusterStatus为normal；有任意一项检查不通过，clusterStatus为abnormal； |

  

**CheckStatusResponse**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| clusterInstanceStatus | String | 集群中实例状态检查结果，有两种取值。Yes表示检查通过，No表示检查不通过。 |
| clusterTopology | String | 集群中实例拓扑信息检查结果，有两种取值。Yes表示检查通过，No表示检查不通过。 |
| clusterMySQLIsAlived | String | 实例探活检查结果，有两种取值。Yes表示检查通过，No表示检查不通过。 |
| clusterDelay | String | 集群延迟状态检查结果，有两种取值。Yes表示检查通过，No表示检查不通过。 |
| leaderReadOnly | String | 若实例属于热活组，检查热活组内leader是否非只读，follower是否只读 |
