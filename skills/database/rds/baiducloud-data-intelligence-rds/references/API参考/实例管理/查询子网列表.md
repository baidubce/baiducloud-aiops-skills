# 查询子网列表

**接口说明**

本接口用于查询子网列表。

**请求结构**

Plain Text

```
GET /v{version}/subnet?zoneName=${zoneName}&vpcId=${vpcId} HTTP/1.1
HOST: rds.bj.baidubce.com
Authorization:authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 参数类型 | 是否必须 | 参数位置 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | 1 | API 版本号 |
| zoneName | String | 否 | Query参数 | cn-bj-b | 子网名称，子网名称由国家-地区-子网编号(a-f)注意 子网序列必须a-f的任意一个字母， 否则将解析错误。例如北京可用区A为"cn-bj-a" |
| vpcId | String | 否 | Query参数 | vpc-70pxg3pmv8rv | 子网VPC ID |

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| subnets | List <SubnetVo> | 子网列表 |

**子网列表**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| name | String | 子网名称 |
| subnetId | String | 子网ID |
| az | String | zone+子网序列 ,例如:zoneA |
| cidr | String | IPV4地址及子网掩码 例如：192.168.0.0/20 |
| ipv6Cidr | String | IPV6地址及子网掩码 例如：240c:4081:8005:2e03::/64 |
| vpcId | String | vpcID |
| vpcShortId | String | vpc短ID |
| subnetUuid | String | 子网序列ID |
| accountId | String | 账户ID |
| subnetType | Intger | 设备类型 BCC(1), BBC（2）, BCC\_NAT（3）,BBC\_NAT（4） |
| type | Intger | 网络类型 未分配（-1） VPC(0),SUBNET(1),ROUTE\_TABLE(2), ROUTE\_RULE(3), ACL\_RULE(4), ENI(5); |
| createdTime | String | 创建时间 |
| updatedTime | String | 更新时间 |
| description | String | 描述 |
| shortId | String | 子网短ID |
| usedIps | Integer | 使用连接数 |
| totalIps | Integer | 总数连接数 |
| tags | List<Tag> | 分组标签 |
| zoneName | String | 区域名称 |
| enable\_ipv6 | String | IPV6 json字符串 |

**分组标签**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| tagKey | String | 标签名 |
| tagValue | String | 标签值 |
