# 更新实例公网访问状态

**接口说明**

更新实例公网访问状态

**请求结构**

Plain Text

```
PUT /v{version}/instance/{instanceId}?modifyPublicAccess HTTP/1.1
HOST: rds.bj.baidubce.com
Authorization: authorization string
{
  publicAccess:publicAccess
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 参数类型 | 是否必须 | 参数位置 | 描述 | 示例值 |
| --- | --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号 | 1 |
| instanceId | String | 是 | URL参数 | 实例ID | rds-4xSw4VMT |
| publicAccess | Boolean | 是 | requestBody 参数 | true：开启公网访问 false：关闭公网访问 | true |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无

**请求示例**

Plain Text

```
PUT /v1/instance/rds-4xSw4VMT?modifyPublicAccess  HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de 
{
  "publicAccess":true
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 7869616F-7A68-6977-656E-406261696475
Content-Type: application/json
Server:BWS
```
