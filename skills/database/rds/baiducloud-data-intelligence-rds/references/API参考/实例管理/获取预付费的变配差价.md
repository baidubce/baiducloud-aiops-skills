# 获取预付费的变配差价

### 接口描述

本接口用于获取预付费的变配差价。

本接口为v1接口。

### 请求结构

Plain Text

```
POST /v{version}/instance/price/diff HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
Content-Type: application/json;charset=UTF-8
{
    "instanceId": "rds-dscvc",
    "diskIoType": "cloud_enha",
    "cpuCount": 1,
    "allocatedMemoryInGB": 2,
    "allocatedStorageInGB": 345,
    "category": ""
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号。 |
| instanceId | String | 是 | RequestBody参数 | 实例 ID。 |
| cpuCount | Integer | 是 | RequestBody参数 | CPU 个数。 |
| allocatedMemoryInGB | Integer | 是 | RequestBody参数 | 内存大小，单位是 MB。 |
| allocatedStorageInGB | Integer | 是 | RequestBody参数 | 存储大小，单位是 GB。 |
| diskIoType | String | 是 | RequestBody参数 | 存储磁盘包括本地SSD磁盘（取值为：normal\_io）、增强型SSD云磁盘（取值为：cloud\_enha）、 高性能云磁盘（取值为：cloud\_high）、cloud\_nor（取值为: 通用型SSD）四种。 |
| category | String | 否 | RequestBody参数 | 不传值的话默认为双机版，传 Singleton 则指定为单机版。 |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| price | BigDecimal | 常规价格。 |
| backupInGB | BigDecimal | 备份费用价格。 |

  

### 请求示例

```

Host: rds.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2015-08-11T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
Content-Type: application/json;charset=UTF-8
{
    "instanceId": "rds-defecvdwc",
    "diskIoType": "cloud_enha",
    "cpuCount": 1,
    "allocatedMemoryInGB": 2,
    "allocatedStorageInGB": 345,
}
```

    "price": 0.00,
