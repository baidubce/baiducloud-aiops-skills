# 查询可用区列表

**接口说明**

获取可用区列表

本接口版本V1

**请求结构**

Plain Text

```
GET /v{version}/zone HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 参数类型 | 是否必选 | 参数位置 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | 1 | API版本号 |

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| zones | List<ZoneDetail> | 可用区列表 |

**可用区列表**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| zoneNames | List <String> | 可用区名称的列表，显示当前的可用区名称 |
| apiZoneNames | List <String> | api可用区名称列表，显示当前的可用区名称，这个字段属于openApi专属字段 |
| available | Boolean | 可用区状态：true(可用) ， false(不可用) |
| zoneNameStr | String | 当前可用区名称 |
| defaultSubnetId | String | 默认子网ID |
| maxCpuCount | Intger | 可用区，统计最大CPU数 |
| maxMemory | Intger | 可用区，最大数量 |
| maxStorage | Intger | 可用区，最大磁盘存储容量 |
| supportNvmeDisk | Boolean | 是否支持Nvme磁盘。 true（支持），false（不支持） |

Plain Text

```
GET /v1/zone HTTP/1.1
Host: rds.bj.baidubce.com

```
