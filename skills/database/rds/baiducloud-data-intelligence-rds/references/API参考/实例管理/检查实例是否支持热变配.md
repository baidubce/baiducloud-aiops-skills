# 检查实例是否支持热变配

### 接口描述

本接口用于检查实例是否支持热变配。

本接口为v1接口。

### 请求结构

Plain Text

```
POST /v{version}/instance/{instanceId}/checkHotUpgrade HTTP/1.1
Host: rds.bj.baidubce.com
Authorization: authorization string
Content-Type: application/json;charset=UTF-8
{
  "instanceId": "instanceId",
  "cpuCount" : 1,
  "allocatedMemoryInMB" : 1024,
  "allocatedStorageInGB": 50,
  "masterAzone": "cn-bj-a",
  "backupAzone": "cn-bj-a",
  "subnetId": "sbn-IyWRnII7",
  "edgeSubnetId": "sbn-IyWRnIef"
}
```

### 请求头域

除公共头域外，无其它特殊头域。

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | API版本号。 |
| instanceId | String | 是 | URL参数 | 实例 ID。 |
| instanceId | String | 是 | RequestBody参数 | 实例 ID。 |
| cpuCount | Integer | 是 | RequestBody参数 | CPU个数。 |
| allocatedMemoryInMB | Integer | 是 | RequestBody参数 | 实例内存大小，单位是MB。 |
| allocatedStorageInGB | Integer | 是 | RequestBody参数 | 实例存储大小，单位是GB。 |
| masterAzone | String | 是 | RequestBody参数 | 主可用区，例如cn-bj-a。 |
| backupAzone | String | 否 | RequestBody参数 | 备可用区，例如cn-bj-a。 |
| subnetId | String | 是 | RequestBody参数 | 子网ID。 |
| edgeSubnetId | String | 否 | RequestBody参数 | 边缘子网ID。 |

  

### 响应头域

除公共头域外，无其它特殊头域。

### 响应参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| supportHotUpgrade | Integer | 是否支持热变配。0: 不支持；1: 支持 |
