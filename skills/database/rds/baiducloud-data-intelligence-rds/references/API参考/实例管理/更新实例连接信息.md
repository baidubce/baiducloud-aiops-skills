# 更新实例连接信息

**接口说明**

更新实例连接信息

本接口版本V1

**请求结构**

Plain Text

```
PUT /v{version}/instance/{instanceId}?modifyEndpoint HTTP/1.1
HOST: rds.bj.baidubce.com
Authorization: authorization string
{
 "address" : "localhost"
}
```

**请求头域**

除公共头域外，无其它特殊头域

**请求参数**

| 参数名称 | 参数类型 | 是否必须 | 参数位置 | 描述 | 示例值 |
| --- | --- | --- | --- | --- | --- |
| version | String | 是 | URL 参数 | API版本号 | 1 |
| instanceId | String | 是 | URL 参数 | 实例ID | rds-Qob8JN7m |
| address | String | 是 | requestBody | 域名前缀。域名前缀 由小写字母和数字组 成，以小写字母开头 ，长度在3-30之间 | mysql55 |

**返回头域**

除公共头域外，无其它特殊头域

**返回参数**

无

**请求示例**

Plain Text

```
PUT /v1/instance/rds-Qob8JN7m?modifyEndpoint HTTP/1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "address" : "mysql55"
}
```
