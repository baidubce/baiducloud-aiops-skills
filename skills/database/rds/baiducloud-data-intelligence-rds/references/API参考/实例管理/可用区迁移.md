# 可用区迁移

**接口说明**

可用区迁移

* 可用区迁移过程中会有秒级闪断，请确保相关业务程序具有重连机制。
* 建议您在业务低峰期进行可用区迁移操作。
* 多可用区容灾能力更强，但使用延迟较大，请您谨慎选择。

**请求结构**

Plain Text

```
PUT /v{version}/instance/{instanceId}/azoneMigration HTTP/1.1
HOST: rds.bj.baidubce.com
Authorization: authorization string
{
    "master_azone":"master_azone",
    "backup_azone":"backup_azone",
    "zoneNames":[zoneNames],
    "subnets":[
        {
            "zoneName": zoneName,
            "subnetId": subnetId
        }
    ],
    "effectiveTime": "effectiveTime"
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API 版本号 |
| instanceId | String | 是 | URL参数 | 实例ID |
| master\_azone | String | 是 | RequestBody参数 | 主可用区 |
| backup\_azone | String | 是 | RequestBody参数 | 备可用区 |
| zoneNames | List<String> | 是 | RequestBody参数 | 可用区 |
| subnets | List<SubnetMap> | 是 | RequestBody参数 | 可用区子网 |
| effectiveTime | String | 是 | RequestBody参数 | 切换生效时间，默认值：immediate。 - immediate：立即生效； - timewindow：在时间窗口内进行切换或者重启等短暂影响业务的动作。 |

**SubnetMap字段数据结构说明**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| zoneName | String | 可用区 |
| subnetId | String | 子网ID |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**
