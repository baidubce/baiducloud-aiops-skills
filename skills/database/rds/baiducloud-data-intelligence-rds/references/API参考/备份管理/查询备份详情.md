# 查询备份详情

**接口说明**

* 查询备份详情信息，下载链接有效时间为 1800 秒。下载有效时间是下载链接的有效时间，而非下载时间。

**请求结构**

Plain Text

```
GET /v{version}/instance/{instanceId}/backup/{backupId} Http 1.1
HOST: rds.bj.baidubce.com
Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域

**请求参数**

| 参数名称 | 参数类型 | 是否必须 | 描述 | 示例值 | 参数位置 |
| --- | --- | --- | --- | --- | --- |
| version | Integer | 是 | API版本号 | 1 | URL 参数 |
| instanceId | String | 是 | 实例 ID | rds-Qob8JN7m | URL 参数 |
| backupId | String | 是 | 备份 ID | 1689087605048013371 | URL 参数 |

**返回头域**

除公共头域外，无其它特殊头域

**返回参数**

| 参数名称 | 参数类型 | 描述 |
| --- | --- | --- |
| backupId | String | 备份 ID |
| backupSize | Long | 实例大小 ，单位MB |
| backupType | String | 备份类型:  manual(手工创建) automated(自动创建) |
| backupStatus | String | 备份状态  creating(创建中) available(备份可用)   deleting(正在删除) |
| backupStartTime | String | 备份开始时间 |
| backupEndTime | String | 备份结束时间 |
| downloadUrl | String | 下载URL |
| multiDownloadUrl | List MultiDownloads | 下载URL信息，当前字段仅针对 SqlServerL 类型实例 |
| downloadExpires | String | 下载过期时间 |

**MultiDownloads**

| 参数名称 | 参数类型 | 描述 |
| --- | --- | --- |
| dbName | String | 数据库名称 |
| downloadName | String | 下载链接名称 |
| downloadSize | Long | 备份大小，单位为 Byte |
| downloadUrl | String | 备份下载链接 |
