# 查询备份列表

**接口说明**

查询备份列表

**请求结构**

Plain Text

```
GET /v{version}/instance/{instanceId}/backup?marker={marker}&maxKeys={maxKeys} http 1.1
HOST: rds.bj.baidubce.com
Authorization:authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 参数类型 | 是否必须 | 参数位置 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | 1 | API版本号 |
| instanceId | String | 是 | URL参数 | rds-JGroEX60 | 实例ID列表 |
| marker | String | 否 | Query参数 | -1 | 查找的分页的backupId，默认值为-1，表示第一页 |
| maxKeys | Integer | 否 | Query参数 | 1000 | 每一页的分页条数，默认值为1000 |

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

| 参数名称 | 参数类型 | 描述 |
| --- | --- | --- |
| marker | String | 查找的分页的backupId，默认为-1 |
| isTruncated | Boolean | 是否还有下一页，如果有此选项为true，如果没有则为false |
| nextMarker | String | 下一页backupId值，如果有此选项不为空，没有则为空 |
| backups | List<OpenApiBackup> | 备份对象 |

**OpenApiBackup**

| 参数名称 | 参数类型 | 描述 |
| --- | --- | --- |
| backupId | String | 备份 ID |
| backupSize | Long | 实例大小，单位MB |
| backupType | String | 备份类型 manual(手工创建)， automated(自动创建) |
| backupStatus | String | 备份状态。  creating(创建中) available(备份可用)   deleting(正在删除) |
| backupStartTime | String | 备份开始时间 |
| backupEndTime | String | 备份结束时间 |
| downloadUrl | String | 下载URL |
| downloadExpires | String | 下载有效期 |
