# 手动发起全量的物理备份

**接口说明**

* 手动发起全量的物理备份
* 本接口版本v1接口

**注意事项**

此接口请求保证实例在运行中

**请求结构**

Plain Text

```
POST /v{version}/instance/{instanceId}/backup HTTP/1.1
HOST: rds.bj.baidubce.com
Authorization:authorization string
{
 "instanceId":"instanceId_example",
 "effectiveTime":"timewindow",
 "dataBackupType":"physical"
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 参数类型 | 是否必须 | 参数位置 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | 1 | API 版本号 |
| instanceId | String | 是 | URL参数 | rds-zSJynSol | 实例 ID |
| effectiveTime | String | 否 | RequestBody参数 | timewindow | 窗口字段。操作执行方式，有两种取值：timewindow、immediate。其中timewindow表示在时间窗口内执行，immediate表示立即执行。默认为immediate。实例默认的时间窗口为05:00~06:00 |
| dataBackupType | String | 否 | RequestBody参数 | physical | 备份类型，支持physical/snapshot， 取值为：snapshot，磁盘类型为ssd将不支持快照备份 |

  

**返回头域**

除公共头域外，无其它特殊头域

**返回参数**

无

**请求示例**

Plain Text

```
POST /v1/instance/rds-zSJynSol/backup Http 1.1
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
 "effectiveTime":"timewindow",
 "dataBackupType":"physical"
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
Content-Type: application/json
x-bce-request-id: d8752367-38e8-45e4-b4c7-e53be3137ce5
```
