# 获取错误日志详情

**接口说明**

获取错误日志详情

**请求结构**

Plain Text

```
POST /v{version}/instance/{instanceId}/errorlogs/details
HOST: rds.bj.baidubce.com
Authorization: authorization string
{
  "instanceId": "instanceId",
  "startTime": "startTime",
  "endTime": "endTime",
  "pageNo": pageNo,
  "pageSize": pageSize,
  "role": "role",
  "keyWord": "keyWord"
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 参数类型 | 是否必须 | 参数位置 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | 1 | API 版本号 |
| instanceId | String | 是 | URL参数 | rds-94aXRRV2 | 实例ID |
| instanceId | String | 否 | requestBody参数 | rds-94aXRRV2 | 实例ID |
| startTime | String | 否 | requestBody参数 | "2023-09-26T08:41:36.271Z" | 开始时间 |
| endTime | String | 否 | requestBody参数 | "2023-09-26T09:41:36.271Z" | 结束时间 |
| pageNo | Integer | 否 | requestBody参数 | 1 | 开始页数 1 |
| pageSize | Integer | 否 | requestBody参数 | 2 | 每页行数 ，默认为10 |
| keyWord | String | 否 | requestBody参数 | Logging | 搜索关键词 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

| 参数名称 | 参数类型 | 描述 |
| --- | --- | --- |
| count | Integer | 慢日志数量 |
| errorLogs | List<LogErrorDetail> | 错误日志对象 |

**LogErrorDetail**

| 参数名称 | 参数类型 | 描述 |
| --- | --- | --- |
| instanceId | String | 实例ID |
| executeTime | String | 执行时间 |
| logText | String | 日志内容 |
| logLevel | String | 日志级别 |

**请求示例**

Plain Text

```
POST /v1/instance/rds-94aXRRV2/errorlogs/details
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2023-07-27T:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "instanceId": "rds-94aXRRV2",
  "startTime": "2023-09-25T09:38:19Z",
  "endTime": "2023-09-26T09:38:19Z",
  "pageNo": 1,
  "pageSize": 2,
  "keyWord": "Logging"
}
```
