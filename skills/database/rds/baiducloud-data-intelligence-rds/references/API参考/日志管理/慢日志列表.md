# 慢日志列表

**接口说明**

查询慢日志列表

**请求结构**

Plain Text

```
GET /v{version}/instance/{instanceId}/slowlogs/logList/{datetime}  HTTP/1.1
HOST: rds.bj.baidubce.com
Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 参数类型 | 是否必须 | 参数位置 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| version | Interger | 是 | URL参数 | 1 | API版本号 |
| instanceId | String | 是 | URL参数 | rds-94aXRRV2 | 实例ID |
| datetime | String | 是 | URL参数 | 2023-07-29T19:48:05Z | 慢日志时间 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

| 参数名称 | 参数类型 | 描述 |
| --- | --- | --- |
| slowlogs | List<OpenapiSlowlog> | 慢日志下载对象 |

**OpenapiSlowlog**

| 参数名称 | 参数类型 | 描述 |
| --- | --- | --- |
| slowlogId | String | 慢日志ID |
| slowlogSizeInBytes | Long | 慢日志大小 |
| slowlogStartTime | String | 慢日志开始时间 |
| slowlogEndTime | String | 慢日志结束时间 |

**请求示例**

Plain Text

```
GET /v1/instance/rds-94aXRRV2/slowlogs/logList/2023-08-08T03:28:11Z
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-30T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
Content-Type: application/json;charset=UTF-8
x-bce-request-id: d8752367-38e8-45e4-b4c7-e53be3137ce5
{
  slowlogs: [{
    "slowlogId": "slowlog.202307300005",
    "slowlogSizeInBytes": 205,
    "slowlogStartTime": "2023-07-29T16:05:53Z",
    "slowlogEndTime": "2023-07-29T16:05:53Z"
  }]
}
```
