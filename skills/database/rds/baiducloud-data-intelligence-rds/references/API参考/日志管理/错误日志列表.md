# 错误日志列表

**接口说明**

查询错误日志列表

**请求结构**

Plain Text

```
GET /v{version}/instance/{instanceId}/errorlogs/logList/{datetime}  HTTP/1.1
HOST: rds.bj.baidubce.com
Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 参数类型 | 是否必须 | 参数位置 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| version | Interger | 是 | URL参数 | 1 | API版本号 |
| instanceId | String | 是 | URL参数 | rds-94aXRRV2 | 实例ID |
| datetime | String | 是 | URL参数 | 2023-07-28 16:43:39 | UTC 日期时间（比如要查询 2023-07-28 的日志，则该参数取值 2023-07-28 16:43:39） |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

| 参数名称 | 参数类型 | 描述 |
| --- | --- | --- |
| errorlogs | List<OpenapiErrorlog> | 错误日志对象 |

**OpenapiErrorlog**

| 参数名称 | 参数类型 | 描述 |
| --- | --- | --- |
| errorlogId | String | 错误日志id |
| errorlogSizeInBytes | Long | 错误日志大小 |
| errorlogStartTime | String | 错误日志开始时间 |
| errorlogEndTime | String | 错误日志结束时间 |

**请求示例**

Plain Text

```
GET /v1/instance/rds-94aXRRV2/errorlogs/logList/2023-08-08 16:43:39
HOST: rds.bj.baidubce.com
Content-Type: application/json
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2022-10-17T11:12:14Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 7869616F-7A68-6977-656E-406261696475
Content-Type: application/json
{
  "errorlogs": [
    {
      "errorlogId": "errorlog.202307281643",
      "errorlogSizeInBytes": 8030,
      "errorlogStartTime": "2023-07-28T08:43:28Z",
      "errorlogEndTime": "2023-07-28T09:50:52Z"
    }
  ]
}
```
