# 获取慢日志详情

**接口说明**

获取慢日志详情。

**请求结构**

Plain Text

```
POST /v{version}/instance/{instanceId}/slowlogs/details
HOST: rds.bj.baidubce.com
Authorization: authorization string
{
  "instanceId": "instanceId",
  "startTime": "startTime",
  "endTime": "endTime",
  "pageNo": pageNo,
  "pageSize": pageSize,
  "role": "role",
  "dbName": [""],
  "userName: [""],
  "hostIp": [""],
  "sql": "sql"
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 参数类型 | 是否必须 | 参数位置 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| version | Integer | 是 | URL参数 | 1 | API版本号 |
| instanceId | String | 是 | URL参数 | rds-94aXRRV2 | 实例ID |
| instanceId | String | 否 | requestBody参数 | rds-94aXRRV2 | 实例ID |
| startTime | String | 否 | requestBody参数 | "2023-09-26T08:41:36.271Z" | 开始时间 |
| endTime | String | 否 | requestBody参数 | "2023-09-26T09:41:36.271Z" | 结束时间 |
| pageNo | Integer | 否 | requestBody参数 | 1 | 开始页数 1 |
| pageSize | Integer | 否 | requestBody参数 | 2 | 每页行数 ，默认为10 |
| dbName | List<String> | 否 | requestBody参数 | db\_123 | 默认为：数据库名称 |
| hostIp | List<String> | 否 | requestBody参数 | localhost | 主机名 |
| userName | List<String> | 否 | requestBody参数 | test\_user | 用户名 |
| sql | String | 否 | requestBody参数 | sleep(1) | sql语句 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

| 参数名称 | 参数类型 | 描述 |
| --- | --- | --- |
| count | integer | 慢日志数量 |
| slowLogs | List<LogSlowDetail> | 慢日志对象 |

**LogSlowDetail**

| 参数名称 | 参数类型 | 描述 |
| --- | --- | --- |
| instanceId | String | 返回长实例ID |
| userName | String | 用户名 |
| dbName | String | 数据库名 |
| hostIp | String | 主机IP |
| queryTime | Double | 查询时间 |
| lockTime | Double | 锁时间 |
| rowsExamined | Long | 检查行数 |
| rowsSent | Long | 发送行数 |
| sql | String | sql语句 |
| executeTime | String | 执行时间 |
