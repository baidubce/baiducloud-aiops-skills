# 查询错误日志

**前提条件**

* 已创建 MongoDB 实例，并获取实例ID（instanceId）。
* 当前账号具有目标实例的 MongoDB READ、OPERATE 权限。

**说明**

* 本接口用于查询 MongoDB 实例指定节点的错误日志记录。
* 支持按时间范围筛选，支持分页查询（marker 游标模式）。

**请求结构**

Plain Text

```
GET /v1/instance/{instanceId}/queryErrorLogRecords?queryErrorLogRecords&memberId={memberId}&startTime={startTime}&endTime={endTime}&limit={limit}&marker={marker} HTTP/1.1
HOST: mongodb.{region}.baidubce.com
Authorization: authorization string
x-bce-security-token: security-token
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| instanceId | String | 是 | Path参数 | MongoDB 实例短 ID，用于定位实例并进行 ID 权限校验。 |
| queryErrorLogRecords | String | 是 | Query参数 | 路由标识参数；只需要带上该参数即可命中本接口。 |
| memberId | String | 否 | Query参数 | 节点 ID，例如 mongos、shard 或副本集节点ID |
| startTime | String | 否 | Query参数 | 查询开始时间，推荐 ISO 8601 格式（如 2026-07-03T00:00:00Z）。字符串格式透传后端日志服务。 |
| endTime | String | 否 | Query参数 | 查询结束时间，推荐 ISO 8601 格式（如 2026-07-03T01:00:00Z）。字符串格式透传后端日志服务。 |
| limit | Integer | 否 | Query参数 | 单次返回记录数量上限，默认 1000。 |
| marker | String | 否 | Query参数 | 分页游标；首次查询可不传，继续翻页时传上一次返回的 nextMarker。 |

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| result | Array | 错误日志记录列表。 |
| truncated | Boolean | 是否还有后续数据。true 表示结果被截断，需继续分页查询。 |
| marker | String | 当前请求使用的分页游标。 |
| nextMarker | String | 下一页分页游标；truncated 为 true 时用于下一次请求的 marker。 |

**ErrorLogRecord 数据结构**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| operationTime | String | 日志发生时间，ISO 8601 格式。 |
| category | String | 错误日志分类（如 NETWORK、STORAGE 等）。 |
| content | String | 错误日志内容。 |
| connInfo | String | 连接信息（如客户端 IP:Port）。 |

**请求示例**

Plain Text

```
GET /v1/instance/m-xxxxxx/queryErrorLogRecords?queryErrorLogRecords&memberId=node-dfaaas&startTime=2026-07-03T00:00:00Z&endTime=2026-07-03T01:00:00Z&limit=1000 HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: bce-auth-v1/{accessKeyId}/{timestamp}/1800/host/{signedHeaders}/{signature}
x-bce-security-token: {security-token}
```
