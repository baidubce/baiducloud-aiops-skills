# 查询运行日志列表

查询指定实例指定节点的运行日志。

**说明**

* 实例为非删除状态。
* 实例需要开通运行日志服务。

**请求结构**

Plain Text

```
GET /v{version}/instance/{dbInstanceId}/log?listLogFiles&memberId={memberId}&type={type}&startTime={startTime}&endTime={endTime}  HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号 |
| dbInstanceId | String | 是 | URL参数 | 指定实例Id |
| memberId | String | 是 | URL参数 | 指定节点Id |
| type | String | 否 | URL参数 | 日志服务类型。默认为“running”, 即运行日志 |
| startTime | String | 否 | URL参数 | 查询起始时间。格式为yyyy-MM-ddTHH:mm:ssZ（UTC时间） |
| endTime | String | 否 | URL参数 | 查询结束时间。格式为yyyy-MM-ddTHH:mm:ssZ（UTC时间），必须晚于查询起始时间 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| logs | List<LogFile> | 由运行日志文件组成的数组 |

**LogFile 结构**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| name | String | 日志文件名 |
| startTime | String | 文件记录开始时间，格式为yyyy-MM-ddTHH:mm:ssZ |
| endTime | String | 文件记录结束时间，格式为yyyy-MM-ddTHH:mm:ssZ |
| size | Integer | 文件大小，单位Byte |
| downloadUrl | String | 日志文件下载地址 |
| downloadExpires | Integer | 下载地址有效期，默认86400秒 |
| downloadExpireTime | String | 下载地址失效时间，格式为yyyy-MM-ddTHH:mm:ssZ |
