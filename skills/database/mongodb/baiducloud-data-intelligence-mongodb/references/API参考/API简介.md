# API简介

## 概述

欢迎使用百度智能云数据库 DocDB for MongoDB 。您可以使用本文档介绍的API对云数据库 DocDB for MongoDB 服务进行灵活的操作。

如果您是初次调用百度智能云产品的API，可以观看[API入门视频指南](https://cloud.baidu.com/doc/APIGUIDE/index.html)，快速掌握调用API的方法。

云数据库 DocDB for MongoDB API 提供下列接口类型：

| 接口类型 | 描述 |
| --- | --- |
| 实例相关接口 | 通过实例相关接口对实例进行日常管理，包括：创建实例，获取实例列表，实例详情，变更配置，重启，释放实例，修改实例名称，修改管理员密码，主从切换等操作 |
| 白名单相关接口 | 通过白名单相关接口，可以完成对实例的访问控制操作 |
| 备份相关接口 | 通过备份接口，可以完成对实例的备份和备份策略的设置 |
| 其他接口 | 通过该部分提供的接口，可以快速获取可用区列表 |
