# 获取可恢复的时间区间

**获取可恢复的时间区间**

本接口用于在进行时间点恢复前，获取当前实例可恢复到的时间范围。获取以后，将需要恢复到的目标时间点作为创建新实例的参数`restoreTime`传入，新创建的实例将恢复到该指定时间点。

**请求结构**

Plain Text

```
    GET /v{version}/instance/{dbInstanceId}?getRecovableTimeRange HTTP/1.1
    HOST: mongo.bj.baidubce.com
    Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号。 |
| dbInstanceId | String | 是 | Query参数 | 数据库实例名 |

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| recovableTimeRange | List<Object> | 可恢复的时间段列表 |

**Object**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| startTime | String | 可恢复时间段的起始时间，GMT格式 |
| endTime | String | 可恢复时间段的终止时间，GMT格式 |

**请求示例**

Plain Text

```
    GET /v{version}/instance/m-5SUYE7?getRecovableTimeRange HTTP/1.1
    HOST: mongo.bj.baidubce.com
    Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2021-05-16T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 946002ee-cb4f-4aad-b686-5be55df27f09
Content-Type: application/json;charset=UTF-8
{   
  "recovableTimeRange":[
    {
        "startTime":"2021-05-13T10:00:00:00Z",
        "endTime":"2021-05-15T05:17:29:15Z"
    },
    {
        "startTime":"2021-05-15T21:00:00Z",
        "endTime":"2021-05-17T18:40:15Z"
    }
  ]
}
```
