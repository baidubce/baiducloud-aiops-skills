# 库表恢复到新实例

## 功能说明

调用创建实例接口时，可指定将源实例中的一个或多个数据库或集合恢复到新创建的实例中。支持以下两种恢复方式：

* 按时间点恢复
* 按备份集恢复

###### 请求参数

除以下新增参数外，其余请求参数请参见**创建实例**接口。

| 参数名称 | 参数类型 | 是否必须 | 参数位置 | 描述 | 示例值 |
| --- | --- | --- | --- | --- | --- |
| srcDbInstanceId | String | 是 | body | 源实例 ID。 | m-btVMND |
| srcRegion | String | 是 | body | 源实例所在地域。 | gz |
| restoreTime | String | 否 | body | 恢复时间点，与 **backupId** 二选一。 | 2026-03-19T02:32:43Z |
| backupId | String | 否 | body | 备份集 ID，与 **restoreTime** 二选一。 | backup-GKGnfD |
| tableRestore | Boolean | 是 | body | 是否开启库表恢复，固定为 **true**。 | true |
| tableRestoreParams | List | 是 | body | 待恢复的数据库或集合信息。 | - |

###### TableRestoreItem 数据结构说明

| 参数名称 | 参数类型 | 是否必须 | 描述 |
| --- | --- | --- | --- |
| type | String | 是 | 对象类型，固定为 **database**。 |
| name | String | 是 | 数据库名称。 |
| newName | String | 是 | 恢复后的数据库名称。 |
| subObjects | List | 否 | 数据库包含的集合列表。为空时表示恢复整个数据库。 |

###### SubObjectItem 数据结构说明

| 参数名称 | 参数类型 | 是否必须 | 描述 | 示例值 |
| --- | --- | --- | --- | --- |
| type | String | 是 | 对象类型，固定为 **table**。 | table |
| name | String | 是 | 集合名称。 | coll1 |
| newName | String | 是 | 恢复后的集合名称。 | coll1\_backup |

###### 请求示例二：按备份集恢复

除恢复参数外，其余请求参数与**请求示例一：按时间点恢复**保持一致，仅需将 **restoreTime** 替换为 **backupId**。

Plain Text

```
{
    "backupId": "backup-PQ6gz0",
    "tableRestore": true,
    "tableRestoreParams": [
        {
            "type": "database",
            "name": "dbA",
            "newName": "dbA",
            "subObjects": [
                {
                    "type": "table",
                    "name": "coll1",
                    "newName": "coll1_new"
                }
            ]
        }
    ]
}
```
