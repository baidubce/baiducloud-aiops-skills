# 库表恢复到原实例

Plain Text

```
URL: /v1/instance/{instanceId}?restoreToSrc

Method: PUT
```

说明：将指定备份集（backupId）或指定时间点（restoreTime）的库/表数据，恢复回原实例（源集群）自身。backupId 与 restoreTime 至少传一个。该接口需 FULL\_CONTROL 权限，并对 instanceId 做 ID 级权限校验。

Path Parameters:

| 字段名 | 含义 | 类型 | 取值范围 | 是否必填 | 注意事项 |
| --- | --- | --- | --- | --- | --- |
| instanceId | 目标实例 ID（原集群 DocDB 实例 ID，如 m-CH2TVe） | String | 是 | 框架会用该值覆盖请求体中的 dbInstanceId |  |

Body Parameters:

| 字段名 | 含义 | 类型 | 取值范围 | 是否必填 | 注意事项 |
| --- | --- | --- | --- | --- | --- |
| backupId | 备份集 ID | String | 否 | 与 restoreTime 至少传一个 |  |
| restoreTime | 恢复到的时间点 | String | 格式 2006-01-02T15:04:05Z | 否 | 与 backupId 至少传一个 |
| tableRestore | 克隆恢复到临时实例上 | Boolean | false | 是 | 固定传 false |
| region | 地域 | String | 是 |  |  |
| tableRestoreParams | 恢复对象列表 | List | 是 | 不能为空 |  |
| tableRestoreParams[].type | 恢复对象类型（如 database/table） | String | 否 |  |  |
| tableRestoreParams[].name | 源对象名称 | String | 否 |  |  |
| tableRestoreParams[].newName | 恢复后的新名称 | String | 否 | 不传表示保持原名 |  |
| tableRestoreParams[].subObjects | 子对象列表 | List | 否 |  |  |
| tableRestoreParams[].subObjects[].type | 子对象类型 | String | 否 |  |  |
| tableRestoreParams[].subObjects[].name | 子对象源名称 | String | 否 |  |  |
| tableRestoreParams[].subObjects[].newName | 子对象恢复后的新名称 | String | 否 |  |  |

请求示例（按备份集恢复指定库表）：

```
PUT /v1/instance/m-OTNFIS?restoreToSrc

{
    "backupId": "backup-HbZGGV",
    "tableRestore": false,
    "tableRestoreParams": [
        {
            "type": "database",
            "name": "dbB",
            "newName": "dbb1"
        },
        {
            "type": "database",
            "name": "dbA",
            "newName": "dbA",
            "subObjects": [
                {
                    "type": "table",
                    "name": "coll1",
                    "newName": "coll1"
                }
            ]
        }
    ],
    "region": "gz",
    "dbInstanceId": "m-OTNFIS"
}
```

响应示例：

TSX

```
{"taskGroupId":"1784713293226662001"}
```
