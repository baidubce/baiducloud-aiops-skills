# 更改备份策略

**请求结构**

Plain Text

```
PUT /v{version}/instance/{dbInstanceId}/backupPolicy HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: authorization string
{
  "autoBackupEnable": autoBackupEnable,
  "preferredBackupPeriod": preferredBackupPeriod,
  "preferredBackupTime":preferredBackupTime,
  "enableIncrementBackup": enableIncrementBackup,
  "backupMethod": backupMethod,
  "backupRetentionPeriod": backupRetentionPeriod,
  "incrBackupRetentionPeriod": incrBackupRetentionPeriod
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号 |
| dbInstanceId | String | 是 | URL参数 | 指定实例ID |
| autoBackupEnable | String | 是 | RequestBody参数 | 自动备份状态。 [取值参考](/doc/MONGODB/s/7jwvy6oxh#autobackupenable) |
| preferredBackupPeriod | String | 是 | RequestBody参数 | 备份周期。 [取值参考](/doc/MONGODB/s/7jwvy6oxh#preferredbackupperiod)如需传入多个值，多个值用英文逗号（,）隔开 |
| preferredBackupTime | String | 是 | RequestBody参数 | 备份时间。格式为HH:mmZ-HH:mmZ，时间范围限制为1小时 |
| backupMethod | String | 否 | RequestBody参数 | 备份生成方式。可以为"Physical"或"Snapshot"。 |
| enableIncrementBackup | Integer | 否 | RequestBody参数 | 是否开启增量备份。0：关闭、1：开启,若要开启增量备份，必须开启自动备份（存量），即autoBackupEnable为“ON” |
| backupRetentionPeriod | Integer | 否 | RequestBody参数 | 表示用于设置备份文件保留天数，默认7天；取值范围7~30 |
| incrBackupRetentionPeriod | Integer | 否 | RequestBody参数 | 表示用于设置增量备份文件保留天数，默认7天；取值范围7~30 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无特殊返回参数。

**请求示例**

Plain Text

```
PUT /v1/instance/m-gGWeCM/backup HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2021-05-16T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "autoBackupEnable": "ON",
  "preferredBackupPeriod": "Monday,Wednesday",
  "preferredBackupTime": "01:00Z-02:00Z",
  "enableIncrementBackup": 1,
  "backupMethod": "Physical",
  "backupRetentionPeriod": 7,
  "incrBackupRetentionPeriod": 7
}
```
