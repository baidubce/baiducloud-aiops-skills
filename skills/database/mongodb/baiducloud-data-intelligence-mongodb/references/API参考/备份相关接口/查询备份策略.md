# 查询备份策略

**请求结构**

Plain Text

```
GET /v{version}/instance/{dbInstanceId}/backupPolicy HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号 |
| dbInstanceId | String | 是 | URL参数 | 指定实例ID |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| autoBackupEnable | String | 自动备份状态。 [取值参考](/doc/MONGODB/s/7jwvy6oxh#autobackupenable) |
| preferredBackupPeriod | String | 备份周期。 [取值参考](/doc/MONGODB/s/7jwvy6oxh#preferredbackupperiod)。 如需传入多个值，多个值用英文逗号（,）隔开 |
| preferredBackupTime | String | 备份时间。格式为HH:mmZ-HH:mmZ。时间范围限制为1小时 |
| backupRetentionPeriod | Integer | 备份保留天数 |
| enableIncrementBackup | Integer | 增量备份是否开启。0：未开启；1：已开启 |
| backupMethod | String | 备份生成方式。 |
| incrBackupRetentionPeriod | Integer | 表示用于设置增量备份文件保留天数 |

**请求示例**

Plain Text

```
GET /v1/instance/m-gGWeCM/backupPolicy HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2021-05-16T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 946002ee-cb4f-4aad-b686-5be55df27f09
Content-Type: application/json;charset=UTF-8
{
  "autoBackupEnable": "ON",
  "backupRetentionPeriod": 7,
  "preferredBackupPeriod": "Monday,Wednesday",
  "preferredBackupTime": "01:00Z-02:00Z",
  "enableIncrementBackup": 1
}
```
