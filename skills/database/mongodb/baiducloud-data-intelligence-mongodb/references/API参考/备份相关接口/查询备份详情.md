# 查询备份详情

**请求结构**

Plain Text

```
GET /v{version}/instance/{dbInstanceId}/backup/{backupId} HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号 |
| dbInstanceId | String | 是 | URL参数 | 指定实例ID |
| backupId | String | 是 | URL参数 | 指定备份ID |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| backupId | String | 备份ID |
| backupSize | String | 备份大小。单位Byte |
| backupMethod | String | 备份方式，[取值参考](/doc/MONGODB/s/7jwvy6oxh#backupmethod) |
| bakupMode | String | 备份模式，[取值参考](/doc/MONGODB/s/7jwvy6oxh#backupmode) |
| backupType | String | 备份类型，[取值参考](/doc/MONGODB/s/7jwvy6oxh#backuptype) |
| backupStatus | String | 备份状态，[取值参考](/doc/MONGODB/s/7jwvy6oxh#backupstatus) |
| backupStartTime | DateTime | 备份开始时间 |
| backupEndTime | DateTime | 备份结束时间 |
| downloadUrl | String | 备份下载地址 |
| downloadExpires | String | 下载地址过期时间。单位s |
| backupDescription | String | 备份详情 |

**请求示例**

Plain Text

```
GET /v1/instance/m-gGWeCM/backup/backup-04oeZM HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2021-05-16T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
```
