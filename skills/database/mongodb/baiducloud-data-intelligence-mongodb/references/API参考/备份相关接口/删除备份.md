# 删除备份

说明

* 目前只支持删除手动备份，自动备份数据保留天数固定为7天，7天后自动删除。

**请求结构**

Plain Text

```
DELETE /v{version}/instance/{dbInstanceId}/backup/{backupId} HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 |
| --- | --- | --- | --- |
| version | String | 是 | URL参数 |
| dbInstanceId | String | 是 | URL参数 |
| backupId | String | 是 | URL参数 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无特殊返回参数。

**请求示例**

Plain Text

```
DELETE /v1/instance/m-gGWeCM/backup/backup-TBZD2w HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2021-05-16T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 946002ee-cb4f-4aad-b686-5be55df27f09
Content-Type: application/json;charset=UTF-8
```
