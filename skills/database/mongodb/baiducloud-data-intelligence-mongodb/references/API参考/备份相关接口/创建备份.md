# 创建备份

说明

* 副本集实例支持逻辑备份和物理备份；分片集实例只支持物理备份。

**请求结构**

Plain Text

```
POST /v{version}/instance/{dbInstanceId}/backup HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: authorization string
{
  "backupMethod": backupMethod,
  "backupDescription": backupDescription
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号 |
| dbInstanceId | String | 是 | URL参数 | 指定实例ID |
| backupMethod | String | 是 | RequestBody参数 | 备份方式。[取值参考](/doc/MONGODB/s/7jwvy6oxh#backupmethod) |
| backupDescription | String | 否 | RequestBody参数 | 备份备注信息 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| backupId | String | 创建的备份ID |

**请求示例**

Plain Text

```
POST /v1/instance/m-gGWeCM/backup HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2021-05-16T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
  "backupMethod": "Physical",
  "backupDescription": "mybackup"
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 946002ee-cb4f-4aad-b686-5be55df27f09
Content-Type: application/json;charset=UTF-8
{
  "backupId":"backup-TBZD2w"
}
```
