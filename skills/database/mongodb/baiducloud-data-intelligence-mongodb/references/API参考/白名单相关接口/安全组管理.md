# 安全组管理

通过绑定 VPC 安全组，可以将安全组中的 IP 作为 MongoDB 实例白名单来源统一管理。本文包含绑定或解绑安全组，以及查询当前实例已关联安全组两个接口。

## 注意事项

* 创建、绑定和解绑操作需要 `OPERATE` 权限；查询操作需要 `READ` 或 `OPERATE` 权限。
* 解绑安全组只解除安全组与实例白名单的关联，不会删除安全组本身。
* 实例必须处于允许安全组操作的状态。

## 费用说明

接口本身不产生额外费用。VPC 安全组及 MongoDB 实例的资源费用按对应产品计费规则收取。

## 1. 修改安全组（绑定/解绑）

### 请求结构

```
PUT /v1/instance/{instanceId}?modifySecurityGroup HTTP/1.1
Host: mongodb.bj.baidubce.com
Authorization: authorization string
Content-Type: application/json
```

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| instanceId | String | 是 | URL 参数 | 实例 ID。 |
| action | String | 是 | 请求 Body | 操作类型：`bind` 表示绑定，`unbind` 表示解绑。 |
| securityGroupIds | Arraystring | 是 | 请求 Body | 安全组 ID 列表，不能为空。 |

### 请求示例

```
PUT /v1/instance/m-i5hAjk?modifySecurityGroup HTTP/1.1
Host: mongodb.bj.baidubce.com
Authorization: authorization string
Content-Type: application/json

{
  "action": "bind",
  "securityGroupIds": ["sg-abc12345", "sg-def67890"]
}
```

### 返回参数

无。接口成功时返回 HTTP `200 OK`。

### 返回示例

```
HTTP/1.1 200 OK
```

## 2. 查询白名单中的安全组列表

### 请求结构

```
GET /v1/instance/{instanceId}/listSecurityGroupsInWhitelist?listSecurityGroupsInWhitelist HTTP/1.1
Host: mongodb.bj.baidubce.com
Authorization: authorization string
```

### 请求参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| instanceId | String | 是 | URL 参数 | 实例 ID。 |
| listSecurityGroupsInWhitelist | String | 是 | Query 参数 | 固定查询标识，取值为`listSecurityGroupsInWhitelist`。 |

### 返回参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| securityGroups | `Array<Object>` | 当前实例已关联的安全组列表。 |
| securityGroups[].shortId | String | 安全组短 ID。 |
| securityGroups[].uuid | String | 安全组 UUID。 |
| securityGroups[].name | String | 安全组名称。 |
| securityGroups[].desc | String | 安全组描述。 |
| securityGroups[].vpcId | String | 安全组所属 VPC ID。 |

### 请求示例

```
GET /v1/instance/m-i5hAjk/listSecurityGroupsInWhitelist?listSecurityGroupsInWhitelist HTTP/1.1
Host: mongodb.bj.baidubce.com
Authorization: authorization string
```

### 返回示例

```
{
  "securityGroups": [
    {
      "shortId": "sg-abc12345",
      "uuid": "90a1f5c8-b2d4-4e6f-8a9b-c1d2e3f4a5b6",
      "name": "production-group",
      "desc": "Production security group",
      "vpcId": "vpc-xyz98765"
    }
  ]
}
```
