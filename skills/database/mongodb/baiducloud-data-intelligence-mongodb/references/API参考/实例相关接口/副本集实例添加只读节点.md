# 副本集实例添加只读节点

**说明**

* 三节点的副本集实例才可以进行添加只读节点操作。
* 添加只读节点时需实例处在RUNNING状态。
* 待添加只读节点个数加上该实例已有只读节点个数不能超过5个。
* 异步接口，可通过调用实例详情接口查看实例状态。
* 作为一个可选项，您可以为新增节点指定当前实例VPC下的其他可用区

**请求结构**

Plain Text

```
PUT /v{version}/instance/{dbInstanceId}?resize&clientToken={clientToken} HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: authorization string
{
    "readonlyNodeNum": readonlyNodeNum,
     "subnet":{
        "zoneName": zonename,
        "subnetId": subnetID
     } 
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号 |
| clientToken | String | 是 | Query参数 | 幂等性Token，是一个长度不超过64位的ASCII字符串。 |
| dbInstanceId | String | 是 | URL参数 | 指定实例ID |
| readonlyNodeNum | int | 是 | RequestBody参数 | 只读节点添加个数。待添加只读节点个数加上该实例已有只读节点个数不能超过5个 |
| subnet | [SubnetModel](https://cloud.baidu.com/doc/MONGODB/s/7jwvy6oxh#subnetmodel) | 否 | RequestBody参数 | 为新增节点指定当前VPC下的其他可用区，如果不提供，则根据分配规则自动分配可用区。可通过调用[查询可用区列表](https://cloud.baidu.com/doc/MONGODB/s/6jwvy6ngq#%E8%8E%B7%E5%8F%96%E5%8F%AF%E7%94%A8%E5%8C%BA%E5%88%97%E8%A1%A8)接口查询可用区列表。 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| orderId | String | 添加只读节点的订单号 |
| readonlyMemberIds | List | 添加的只读节点的ID列表 |

**请求示例**

Plain Text

```
PUT /v1/instance/m-qNlWTz?resize&clientToken=be31b98c-5e41-4838-9830-9be700de5a20 HTTP/1.1
HOST: mongodb.bj.baidubce.com
ContentType: application/json    
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    "readonlyNodeNum": 1,
     "subnet":{
        "zoneName": "cn-bd-c",
        "subnetId": "sbn-b01zmnfntvjz"
     }
}
```
