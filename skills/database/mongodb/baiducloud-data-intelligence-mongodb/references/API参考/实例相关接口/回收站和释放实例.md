# 回收站和释放实例

实例释放后实例所使用的物理资源都被收回，相关数据全部丢失且不可恢复。

**说明**

* 只有付费类型为Postpaid或者付费类型为Prepaid且已过期的实例才可以释放。

### 单个实例放入回收站

**请求结构**

Plain Text

```
DELETE /v{version}/instance/{dbInstanceId} HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号 |
| dbInstanceId | String | 是 | Query参数 | 实例ID |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无特殊返回参数

**请求示例**

Plain Text

```
DELETE /v1/instance/m-qNlWTz HTTP/1.1
HOST: mongodb.bj.baidubce.com
ContentType: application/json    
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 7869616F-7A68-6977-656E-406261696475
Content-Type: application/json
Content-Length: 0
```

### 多个实例放入回收站

**请求结构**

Plain Text

```

HOST: mongodb.bj.baidubce.com
Authorization: authorization string

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号 |
| dbInstanceIds | String | 是 | Query参数 | 实例ID。多个实例之间用英文逗号','分割 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

**请求示例**

Plain Text

```
DELETE /v1/instance?dbInstanceIds=m-KKnhbV,m-Hphyd0 HTTP/1.1
HOST: mongodb.bj.baidubce.com
ContentType: application/json    
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
