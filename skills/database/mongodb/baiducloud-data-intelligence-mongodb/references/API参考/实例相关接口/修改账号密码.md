# 修改账号密码

**说明**

修改MongoDB账号的密码。

**请求结构**

Plain Text

```
PUT /v{version}/instance/{dbInstanceId}?resetPassword  HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: authorization string
{
    "accountPassword": accountPassword,
    "accountName": "accountName"
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | string | 是 | URL参数 | API版本号 |
| dbInstanceId | string | 是 | URL参数 | 指定实例Id |
| accountPassword | string | 是 | RequestBody参数 | MongoDB账号的密码，8-32位字符，英文，数字和符号必须同时存在，符号仅限!#$%^\*()。 密码需要加密传输，密码一律采用AES 128位加密算法进行加密，用SK作为密钥，加密后生成的二进制字节流需要转成十六进制，并以字符串的形式传到服务端。步骤如下： byte[] bCiphertext= AES(明文,SK) String strHex = HexStr(bCiphertext) |
| accountName | string | 否 | RequestBody参数 | 用户名称，默认为root |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无特殊返回参数

**请求示例**

Plain Text

```
PUT /v1/instance/m-qNlWTz?resetPassword HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    "accountPassword": "3869616F-7A68-6977-656E-4062BE16782",
    "accountName": "root"
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 7869616F-7A68-6977-656E-406261696475
Content-Type: application/json
Content-Length: 0
```
