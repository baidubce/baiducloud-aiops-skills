# 分片集实例组件改配

为指定分片集实例组件改配。

**说明**

* 只有组件RUNNING状态时才可以进行改配操作。
* 该接口当前支持分片集实例Mongos和Shard组件的变配。
* 异步接口，可通过实例详情接口查看组件状态。

**请求结构**

Plain Text

```
PUT /v{version}/instance/{dbInstanceId}/node/{nodeId}?resize&clientToken={clientToken} HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: authorization string
{
    "nodeCpuCount": nodeCpuCount,
    "nodeMemoryCapacity": nodeMemoryCapacity,
    "nodeStorage": nodeStorage
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | string | 是 | URL参数 | API版本号 |
| clientToken | string | 是 | Query参数 | 幂等性Token，是一个长度不超过64位的ASCII字符串。 |
| dbInstanceId | string | 是 | URL参数 | 指定实例Id |
| nodeId | string | 是 | URL参数 | 指定组件Id |
| nodeCpuCount | int | 是 | RequestBody参数 | cpu核数。[取值参考](/doc/MONGODB/s/7jwvy6oxh#%E5%88%86%E7%89%87%E9%9B%86%E5%AE%9E%E4%BE%8B%E5%8F%AF%E9%80%89%E5%A5%97%E9%A4%90) |
| nodeMemoryCapacity | int | 是 | RequestBody参数 | 内存大小，单位GB。[取值参考](/doc/MONGODB/s/7jwvy6oxh#%E5%88%86%E7%89%87%E9%9B%86%E5%AE%9E%E4%BE%8B%E5%8F%AF%E9%80%89%E5%A5%97%E9%A4%90) |
| nodeStorage | int | 否 | RequestBody参数 | 磁盘大小，单位GB，每1G递增。当组件类型为Shard时，需要传此参数。当组件类型为Mongos时，不需要传此参数。[取值参考](/doc/MONGODB/s/7jwvy6oxh#%E5%88%86%E7%89%87%E9%9B%86%E5%AE%9E%E4%BE%8B%E5%8F%AF%E9%80%89%E5%A5%97%E9%A4%90) |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无特殊返回参数

**请求示例**

Plain Text

```
PUT /v1/instance/m-qNlWTz/node/shd-FI071n?resize&clientToken=be31b98c-5e41-4838-9830-9be700de5a20 HTTP/1.1
HOST: mongodb.bj.baidubce.com
ContentType: application/json    
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    "nodeCpuCount": 2,
    "nodeMemoryCapacity": 4,
    "nodeStorage": 10
}
```

**返回示例**

Plain Text

```
x-bce-request-id: 7869616F-7A68-6977-656E-406261696475
Content-Type: application/json

```
