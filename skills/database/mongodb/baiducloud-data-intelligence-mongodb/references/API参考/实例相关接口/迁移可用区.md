# 迁移可用区

将实例迁移至其他可用区。

**说明**

* 只有实例RUNNING状态时才可以进行变配操作。
* 异步接口，可通过调用实例详情接口查看实例状态。

**请求结构**

Plain Text

```
PUT /v{version}/instance/{dbInstanceId}?migrateAzone HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: authorization string
{
 "subnets": [{
   "subnetId": "subnetId",
   "zoneName": "zoneName"
 }],
 "members": [{
        "subnetId": "subnetId",
        "role": "primary"
    },
    {
        "subnetId": "subnetId",
        "role": "hidden"
    },
    {
        "subnetId": "subnetId",
        "role": "secondary"
    }
  ]
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | string | 是 | URL参数 | API版本号 |
| dbInstanceId | string | 是 | URL参数 | 指定实例Id |
| subnets | SubnetModel | 是 | RequestBody参数 | 子网 |
| subnetId | string | 是 | RequestBody参数 | 子网短id |
| zoneName | string | 是 | RequestBody参数 | 可用区 |
| members | MemberMode | 是 | RequestBody参数 | 角色分布信息 |
| subnetId | string | 是 | RequestBody参数 | 子网短id |
| role | string | 是 | RequestBody参数 | 角色 |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无特殊返回参数
