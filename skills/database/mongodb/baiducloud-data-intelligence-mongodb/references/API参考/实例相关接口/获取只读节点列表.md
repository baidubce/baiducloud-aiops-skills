# 获取只读节点列表

为指定副本集实例获取只读节点的列表。

**说明**

* 只有副本集实例才有可能有只读节点。

**请求结构**

Plain Text

```
 GET /{version}/instance/{dbInstanceId}/getReadonlyNodes HTTP/1.1
 HOST: mongodb.bj.baidubce.com
 ContentType: application/json
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号 |
| dbInstanceId | String | 是 | URL参数 | 指定实例ID |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| readOnlyList | List | 组件列表 |
| +compId | String | 组件ID，即副本集的replicaSet |
| +nodeIds | List | 指定组件的节点列表 |

**请求示例**

Plain Text

```
GET /v1/instance/m-HvP6eO/getReadonlyNodes HTTP/1.1
HOST: mongodb.bj.baidubce.com
ContentType: application/json
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: efeaab9b-eb4a-485d-8745-8ce72f864ffc
Content-Type: application/json
Content-Length: 68

{
    "readOnlyList": [
        {
            "compId": "rep-u5PM9U", 
            "nodeIds": [
                "node-SDOO07"
            ]
        }
    ]
}
```
