# 变更副本集实例配置

为指定副本集实例进行资源改配。

**说明**

* 只有实例RUNNING状态时才可以进行变配操作。
* 异步接口，可通过调用实例详情接口查看实例状态。

**请求结构**

Plain Text

```
PUT /v{version}/instance/{dbInstanceId}?resize&clientToken={clientToken} HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: authorization string
{
    "dbInstanceCpuCount"        : dbInstanceCpuCount,
    "dbInstanceMemoryCapacity"  : dbInstanceMemoryCapacity,
    "dbInstanceStorage"         : dbInstanceStorage
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | string | 是 | URL参数 | API版本号 |
| clientToken | string | 是 | Query参数 | 幂等性Token，是一个长度不超过64位的ASCII字符串。 |
| dbInstanceId | string | 是 | URL参数 | 指定实例Id |
| dbInstanceCpuCount | int | 是 | RequestBody参数 | cpu规格。[取值参考](/doc/MONGODB/s/7jwvy6oxh#%E5%89%AF%E6%9C%AC%E9%9B%86%E5%AE%9E%E4%BE%8B%E5%8F%AF%E9%80%89%E5%A5%97%E9%A4%90) |
| dbInstanceMemoryCapacity | int | 是 | RequestBody参数 | 内存规格，单位GB。[取值参考](/doc/MONGODB/s/7jwvy6oxh#%E5%89%AF%E6%9C%AC%E9%9B%86%E5%AE%9E%E4%BE%8B%E5%8F%AF%E9%80%89%E5%A5%97%E9%A4%90) |
| dbInstanceStorage | int | 是 | RequestBody参数 | 存储规格，单位GB。[取值参考](/doc/MONGODB/s/7jwvy6oxh#%E5%89%AF%E6%9C%AC%E9%9B%86%E5%AE%9E%E4%BE%8B%E5%8F%AF%E9%80%89%E5%A5%97%E9%A4%90) |
| votingMemberNum | int | 否 | RequestBody参数 | 节点数，如您希望转换节点架构，可按需设置值为2或3。更多信息请参考[帮助文档](https://cloud.baidu.com/doc/MONGODB/s/Zkdqu45ej) |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无特殊返回参数

**请求示例**

Plain Text

```
PUT /v1/instance/m-qNlWTz?resize&clientToken=be31b98c-5e41-4838-9830-9be700de5a20 HTTP/1.1
HOST: mongodb.bj.baidubce.com
ContentType: application/json    
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    "dbInstanceCpuCount"        : 2,
    "dbInstanceMemoryCapacity"  : 4,
    "dbInstanceStorage"         : 10,
    "votingMemberNum"         : 2
}
```
