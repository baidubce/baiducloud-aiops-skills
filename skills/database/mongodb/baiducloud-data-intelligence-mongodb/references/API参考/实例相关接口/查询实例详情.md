# 查询实例详情

**说明**

* 查询指定实例的详细信息

**请求结构**

Plain Text

```
GET /v{version}/instance/{dbInstanceId} HTTP/1.1
HOST: mongodb.bj.baidubce.com
Authorization: authorization string
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | string | 是 | URL参数 | API版本号 |
| dbInstanceId | string | 是 | URL参数 | 指定实例Id |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| dbInstanceId | string | 实例ID |
| dbInstanceName | string | 数据库实例名 |
| connectionString | string | 数据库连接地址 |
| port | string | 数据库连接端口 |
| engineVersion | string | 数据库引擎版本。[具体参见](/doc/MONGODB/s/7jwvy6oxh#engineversion) |
| storageEngine | string | 存储引擎。[具体参见](/doc/MONGODB/s/7jwvy6oxh#storageengine) |
| dbInstanceCpuCount | int | 副本集实例CPU规格 |
| dbInstanceMemoryCapacity | int | 副本集实例内存规格，单位GB |
| dbInstanceStorage | int | 副本集实例存储规格，单位GB |
| dbInstanceStorageType | string | 副本集实例存储类型。[具体参见](/doc/MONGODB/s/7jwvy6oxh#storagetype) |
| dbInstanceType | string | 实例类型。[具体参见](/doc/MONGODB/s/7jwvy6oxh#instancetype) |
| mongosCount | int | Mongos组件数量 |
| shardCount | int | Shard组件数量 |
| mongosList | List [NodeModel](/doc/MONGODB/s/7jwvy6oxh#nodemodel) | Mongos组件列表 |
| shardList | List [NodeModel](/doc/MONGODB/s/7jwvy6oxh#nodemodel) | Shard组件列表 |
| votingMemberNum | int | 副本集实例投票节点数量 |
| readonlyNodeNum | int | 副本集实例只读节点数量 |
| dbInstanceStatus | string | 实例状态。参见[实例状态表](/doc/MONGODB/s/7jwvy6oxh#instancestatus) |
| createTime | Datetime | 实例创建时间 |
| expireTime | Datetime | 实例到期时间 |
| vpcId | String | 实例所属VPC的ID |
| publicConnectionString | String | 公网地址连接串 |
| publicReadonlyConnectionString | String | 只读节点的公网地址连接串，副本集有效 |
| readOnlyNodeConnectionString | String | 只读节点的内网地址连接串，副本集有效 |
| paymentTiming | String | 付费方式,参考[付费方式](/doc/MONGODB/s/7jwvy6oxh#%E8%AE%A2%E5%8D%95%E7%9B%B8%E5%85%B3) |
| logServiceStatus | List [LogServiceModel](/doc/MONGODB/s/7jwvy6oxh#logservicemodel) | 实例各种类型日志的状态 |
| members | List [Member](/doc/MONGODB/s/7jwvy6oxh#member) | 副本集实例节点信息 |
| subnets | List [SubnetModel](/doc/MONGODB/s/7jwvy6oxh#subnetmodel) | 实例所在可用区和子网 |
| tags | List [TagModel](/doc/MONGODB/s/7jwvy6oxh#tagmodel) | 实例资源所绑定的标签 |

**请求示例**

Plain Text

```
GET /v1/instance/m-qNlWTz HTTP/1.1
HOST: mongodb.bj.baidubce.com
ContentType: application/json    
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2017-11-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
```
