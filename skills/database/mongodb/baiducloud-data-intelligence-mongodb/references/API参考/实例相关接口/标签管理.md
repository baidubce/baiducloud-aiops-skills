# 标签管理

## 绑定/解绑标签

**说明**

* 当前接口用于为实例绑定、解绑标签信息
* 当前接口仅支持特定枚举操作，不符合的会报错提示

**请求结构**

Plain Text

```
POST /v{version}/instance/tags?action={action} HTTP/1.1
HOST: mongodb.bj.baidubce.com
Content-Type: application/json
Authorization: authorization string
{
    "dbInstanceId": "dbInstanceId",
    "tags": [
        {
            "tagKey": "tagKey",
            "tagValue": "tagValue"
        }
    ]
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | string | 是 | Path参数 | API版本号，取值为1 |
| action | String | 是 | Query参数 | 参数代表当前执行的操作类型，支持的枚举值：绑定标签（bind）、解绑标签（unbind）。 |
| dbInstanceId | string | 是 | RequestBody参数 | MongoDB 实例 ID |
| tags | List | 是 | RequestBody参数 | 要绑定、解绑的标签信息 |

**Tag**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| tagKey | string | 是 | RequestBody参数 | 标签键信息 |
| tagValue | string | 是 | RequestBody参数 | 标签值信息 |

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

无

**请求示例**

Plain Text

```
POST /v1/instance/tags?action=bind HTTP/1.1
HOST: mongodb.bj.baidubce.com
ContentType: application/json    
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2026-01-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    "dbInstanceId": "m-VmX0ZQ",
    "tags": [
        {
            "tagKey": "test3e434",
            "tagValue": "test34343"
        }
    ]
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 7869616F-7A68-6977-656E-406261696475
Content-Type: application/json
Content-Length: 0
```

## 更新标签绑定关系

**说明**

* 当前接口用于更新标签绑定关系
* 当前接口支持批量更新实例标签信息，单次操作的实例个数上限为3个

**请求结构**

Plain Text

```
PUT /v{version}/instance/tags HTTP/1.1
HOST: mongodb.bj.baidubce.com
Content-Type: application/json
Authorization: authorization string
{
    "resources": [
        {
            "dbInstanceId": "dbInstanceId",
            "tags": [
                {
                    "tagKey": "tagKey",
                    "tagValue": "tagValue"
                }
            ]
        }
    ]
}
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | string | 是 | Path参数 | API版本号，取值为1 |
| dbInstanceId | string | 是 | RequestBody参数 | MongoDB 实例 ID |
| tags | List | 是 | RequestBody参数 | 要操作的标签信息 |

**Tag**

| 参数名称 | 类型 | 是否必须 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| tagKey | string | 是 | RequestBody参数 | 标签键信息 |
| tagValue | string | 是 | RequestBody参数 | 标签值信息 |

**返回头域**

除公共头域外，无其它特殊头域。

**返回参数**

无

**请求示例**

Plain Text

```
PUT /v1/instance/tags HTTP/1.1
HOST: mongodb.bj.baidubce.com
ContentType: application/json    
Authorization: bce-auth-v1/f81d3b34e48048fbb2634dc7882d7e21/2026-01-21T04:17:29Z/3600/host/74c506f68c65e26c633bfa104c863fffac5190fdec1ec24b7c03eb5d67d2e1de
{
    "resources": [
        {
            "dbInstanceId": "m-VmX0ZQ",
            "tags": [
                {
                    "tagKey": "test12",
                    "tagValue": "test12121"
                }
            ]
        }
    ]
}
```

**返回示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 7869616F-7A68-6977-656E-406261696475
Content-Type: application/json
Content-Length: 0
```
