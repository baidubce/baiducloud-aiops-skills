# 计费停服和启动服务

## 计费停服和计费停服后启动服务

### 接口描述

因为回收站只能保存7天内释放的实例，如果用户需要将实例停服更长的时间，以保证有足够长的时间确认该实例是否被使用，可以使用计费停服api进行操作。如果仍需要使用该实例，也可以使用启动实例以提供服务。

### 一、计费停服

#### 请求结构

Plain Text

```
PUT /{version}/instance/{dbInstanceId}?stopService HTTP/1.1
HOST: mongodb.bj.baidubce.com
ContentType: application/json
```

**请求头域**

除公共头域外，无其它特殊头域。

**请求参数**

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| version | String | 是 | URL参数 | API版本号 |
| dbInstanceId | String | 是 | URL参数 | 指定实例ID |

**返回头域**

除公共头域，无其它特殊头域。

**返回参数**

无特殊返回参数

**请求示例**

Plain Text

```
PUT /v1/instance/m-iLckz0?stopService HTTP/1.1
HOST: mongodb.bj.baidubce.com
ContentType: application/json
```

**响应示例**

Plain Text

```
HTTP/1.1 200 OK
x-bce-request-id: 7869616F-7A68-6977-656E-406261696475
Content-Type: application/json
Content-Length: 0
```
