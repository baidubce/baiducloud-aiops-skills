# 小版本升级

将 MongoDB 实例的数据库内核升级到最新的小版本，用于获得最新的功能、性能优化和问题修复。

## 注意事项

* 仅当实例处于 `RUNNING`（运行中）状态时可以调用。
* 调用方需要具备实例的 `OPERATE` 权限。
* 升级期间实例可能发生连接闪断或短暂不可用，请提前做好业务重试。
* 目标小版本由服务端根据当前实例可升级版本自动确定，不能指定任意版本。

## 请求结构

```
PUT /v1/instance/{instanceId}?upgradeMinorEngineVersion HTTP/1.1
```

## 请求头域

除公共请求头域外，无其他特殊请求头域。

## 请求参数

### Path 参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| instanceId | String | 是 | URL 参数 | 实例 ID。 |

### Body 参数

| 参数名称 | 类型 | 是否必选 | 参数位置 | 描述 |
| --- | --- | --- | --- | --- |
| executionMode | String | 否 | 请求 Body | 执行方式。`duringMaintenance`：在维护时间窗口执行；不传：立即执行。 |

## 返回头域

除公共响应头域外，无其他特殊响应头域。

## 返回参数

| 参数名称 | 类型 | 描述 |
| --- | --- | --- |
| curVersion | String | 当前数据库小版本。 |
| tarVersion | String | 升级目标数据库小版本。 |

## 请求示例一：立即执行

```
PUT /v1/instance/m-CH2TVe?upgradeMinorEngineVersion HTTP/1.1
Host: mongodb.bj.baidubce.com
Authorization: authorization string
Content-Type: application/json

{}
```

## 请求示例二：维护时间窗口执行

```
PUT /v1/instance/m-CH2TVe?upgradeMinorEngineVersion HTTP/1.1
Host: mongodb.bj.baidubce.com
Authorization: authorization string
Content-Type: application/json

{
  "executionMode": "duringMaintenance"
}
```

## 返回示例

```
{
  "curVersion": "5.0.18",
  "tarVersion": "5.0.19"
}
```
